# 第8章 九楼咖啡

光谷广场附近有一条老街，街角有一家咖啡馆，招牌上写着“九楼咖啡”四个字。

苏晚提前十分钟到了。咖啡馆不大，装修很旧，木质桌椅上有划痕，墙上挂着几张模糊的黑白照片。她找了一个角落的位置坐下，点了一杯美式。

八点差五分，门口进来一个人。

男人，三十二三岁的样子，穿着黑色卫衣，头发遮住半边额头，下巴上是好几天没刮的胡茬。他走进来的时候扫了一眼店内，目光在苏晚身上停留了半秒，然后走过来，在她对面坐下。

“你是苏晚。”

不是疑问句，是陈述句。

“陈驿？”

男人点了点头，从口袋里掏出一包烟，抽出一根叼在嘴上，但没有点。

“美式？”他看了一眼苏晚的杯子，“这家的美式很难喝，苦得像中药。下次换拿铁。”

苏晚没接话，只是看着他。

陈驿把烟从嘴里拿下来，夹在手指间，看着苏晚说：“你带了什么？”

苏晚从包里掏出U盘，放在桌上。

“姜远的日志。七个API调用记录。还有我自己的分析笔记。”

陈驿把U盘拿过去，攥在手里，没有插电脑。他只是捏着那枚小小的金属片，拇指在表面来回摩挲。

沉默持续了大约半分钟。

然后陈驿开口了。

“你查到哪一步了？”

“RULE_032。创建时间是去年10月17日凌晨三点多，IP是10.0.19.42，操作用户是internal_service_account。”苏晚把查到的信息一条一条说出来，“nw-svc仓库，去年9月创建，创建者是system_init。姜远失踪前两天还有代码提交。”

陈驿的手指停了一下。

“还有呢？”

“NightWatch是一个商业化的追踪服务，对外收费，采用订阅制。它能获取用户的完整出行轨迹，包括实时位置和历史POI。姜远调用API的时候查到了自己的位置坐标，坐标指向科技园地下停车场。”

陈驿的表情没有变化，但他把U盘放回了桌上。

“你还查到了什么？”

苏晚犹豫了一下，然后说：“姜远失踪前一周每天都去科技园。他跟他姐姐说，了一件不该发现的事。然后他就失踪了。”

陈驿听到这句话，终于有了一个动作。他把嘴上那根没点的烟放回烟盒里，靠在椅背上，看着苏晚。

“你想知道什么？”

苏晚说：“NightWatch是什么。谁在运营它。那二十一个被过滤的用户是怎么回事。姜远发现了什么。”

陈驿没有立刻回答。

他转头看了一眼窗外。街灯昏暗，有几个路人走过，都低着头，快步走过。

然后他转回来，压低了声音。

“我先告诉你一件事。”他说，“三年前，我发现ETL管道里有一条规则，它会把某些用户从算法里过滤掉。我向上面反映，组长让我别管，领导让我别管，法务说没有违规。我没有办法，只能选择离开。”

苏晚说：“那条规则和现在的RULE_032有关系吗？”

陈驿摇头：“我不知道。三年过去了，我不知道他们换过多少次规则，换过多少套系统。我只知道一件事——那二十一个人不是随机挑选的。”

“是什么意思？”

陈驿的目光变得锐利起来。

“他们是NightWatch的追踪目标。”

苏晚的呼吸停了一拍。

她早就猜到了这个结论，但从陈驿嘴里说出来，感觉完全不一样。

“谁在追踪他们？”

陈驿没有直接回答。他从口袋里掏出手机，打开一个加密文件夹，从里面调出一张截图。

截图上是一个Excel表格，表格里有四列数据：目标姓名、追踪开始时间、追踪结束时间、订阅客户。

苏晚把表格接过来看。

四列数据，每一行都对应一个人。她扫了一眼姓名列表，心跳开始加速——

名单里有姜远的名字。

追踪开始时间是2024年11月3日。追踪结束时间是空白。订阅客户那一列写的是一个公司名称：“武汉恒通数据技术有限公司”。

苏晚把这个名字记在脑子里，然后抬头看陈驿。

“这家公司是做什么的？”

陈驿说：“不知道。但我知道它的实际控制人是谁。”

他把手机收回去，又从加密文件夹里调出另一张截图。

这次是一张工商登记信息的截图。股东一栏里写着一个名字。

苏晚盯着那个名字看了很久。

她认识这个名字。

不是一面之缘的那种认识。是——她见过这个名字很多次，在周报上，在邮件里，在走廊上擦肩而过的时候。

技术总监。周衍。

“周衍有体外公司？”苏晚的声音有点紧。

陈驿把手机收起来，靠回椅背上。

“不只是体外公司。”他说，“NightWatch这个服务，三年前我在公司内部发现它的时候，它还只是一个内部工具。后来有个客户找上门来，想要追踪他老婆的行踪。周衍发现这东西可以收费，就把它商业化了。”

苏晚说：“公司知道吗？”

陈驿冷笑了一声。

“公司？周衍自己就是公司。他的恒通数据技术有限公司是NightWatch的运营主体。nw-svc仓库的代码、10.0.19.42的服务器、RULE_032的过滤规则，全是通过这家公司部署的。不走公司的账，不经过公司的审批，不在公司内网留下任何痕迹。”

苏晚把这些信息在脑子里过了一遍。

“所以NightWatch是一个独立运营的商业服务。周衍是实际控制人。他用公司的平台数据，为自己的公司提供追踪服务。”

陈驿点了点头。

“还不止这些。”他说，“NightWatch的客户不是普通人。能付得起年费订阅一个出行数据追踪服务的人，要么是企业主，要么是调查机构，要么是有钱有势的。你猜他们追踪的是什么人？”

苏晚沉默了几秒。

“竞争对手。婚外情调查。债务人追踪。”她说，“这些在法律上都是灰色地带。”

“对。”“但Grey地带做大了，就是黑色。”

苏晚想起姜远的日志文件。姜远发现了自己被追踪，然后他就失踪了。

“如果NightWatch只是追踪，为什么姜远会失踪？”

陈驿的表情变了。

他没有立刻回答，而是低下头，手指在桌面上轻轻敲了几下。

然后他抬起头，看着苏晚。

“你知道NightWatch的追踪数据是怎么获取的吗？”

苏晚说：“通过平台API ?”

陈驿摇头。

“NightWatch没有直接连公司平台。它的数据来源是算法模型的输入层。”他说，“RULE_032过滤掉的用户，他们的出行数据不会进入算法模型。但这些数据不会凭空消失——它们会被复制一份，存进nw-svc的数据库。”

苏晚明白了。

“所以RULE_032不只是过滤，它还是复制。”

“对。”“过滤是表象，复制才是目的。那些被标记为is_valid=0的用户，他们的真实出行数据会被完整地保存下来，存进NightWatch的数据库，供订阅客户查询。”

苏晚说：“那姜远失踪的事——”

陈驿打断了她。

“姜远发现自己被追踪之后，他做了一件不该做的事。”

“什么事？”

陈驿看着苏晚，目光很沉。

“他查到了NightWatch的订阅客户名单。”

苏晚的心沉了下去。

订阅客户名单。姜远拿到了NightWatch的客户名单，然后他就把这件事告诉了姐姐，然后他就失踪了。

“客户名单上有多少人？”

“不多。十几个。”“但每一个都是付费客户，年费从五万到二十万不等。这些人用NightWatch追踪他们的目标，有的为了商业竞争，有的为了婚外情调查，还有的——”

他

“还有什么？”

陈驿的声音压得更低了。

“还有一个客户，追踪的不是普通人。”

苏晚等着他说下去。

但陈驿没有继续。

他站起身，把U盘从桌上拿起来，还给苏晚。

“今天就到这里。”他说，“你需要时间消化这些信息。”

苏晚把U盘收好，抬头看他：“那个客户追踪的是什么人？”

陈驿站在原地，低头看着她。

有警惕，还有一丝苏晚看不懂的东西。

“那些被追踪的人，”他说，“他们都有一个共同点。”

“是什么？”

陈驿沉默了几秒。

然后他弯下腰，凑近苏晚的耳边，压低声音说了一句话。

那句话让苏晚的血液在一瞬间变凉。

“三年前，有一个NightWatch的客户，追踪了一个不该追踪的人。然后那个人就从所有系统里消失了。”

苏晚的嘴唇动了动，但没有发出声音。

陈驿直起身，把烟盒塞回口袋。

“你查下去会出事。”他说，“姜远就是例子。”

他转身往门口走。

走到门口的时候，他停了一下，回头看了苏晚一眼。

“你现在停下来，还来得及。”

然后他推开门，走进夜色里。

苏晚坐在原地，手心冰凉。

咖啡馆里的暖气开得很足，但她感觉不到任何温度。

三年前，有人被追踪，然后消失了。

姜远发现了那个客户名单，然后他也消失了。

那二十一个人被追踪，然后他们被从系统里过滤掉了。

苏晚把U盘攥在手里，金属边缘硌得掌心有点疼。

陈驿说，你查下去会出事。

但她已经没有退路了。

她已经知道得太多了。

她低头看着杯子里的冷咖啡，脑子里是姜远日志文件里最后一条记录：

```
[2024-09-30 14:29:47] nightwatch_svc API called
Endpoint: /v2/track
Request: {"target_id":"P_5591044728","location_history_depth":"full","scope":"realtime"}
Response: {"status":"success","location":"30.5782,114.2917","accuracy":"15m","timestamp":"2024-09-30T14:29:47Z","additional_info":{"target_name":"姜远","device_id":"xiaomi_13_8T5K92","last_seven_days_poi":["科技园C栋","光谷大道星巴克","光谷广场地铁站","星火苑小区","科技园地下停车场"]}}
```

姜远在日志里看到了自己的名字。

他知道自己被追踪了。

然后他就失踪了。

苏晚合上眼睛，在黑暗里站了很久。

然后她站起来，拿起包，走出咖啡馆。

街道空旷，远处有几辆车驶过。她站在路边，看着自己呼出的白气在灯光下散开。

三年前，有人被追踪，消失了。

姜远发现了真相，失踪了。

那二十一个人被追踪，被过滤，被从系统里抹去。

苏晚不知道那个“不该追踪的人”是谁，也不知道三年前到底发生了什么。

但她知道一件事：

NightWatch不只是一个追踪服务。

它是把人的痕迹从现实世界抹掉的工具。

问题不是它怎么做到的。是——谁在用。
