# 第12章 不归点

周五下午五点四十二分，苏晚收到了陈驿的消息。

消息只有一个字：“小心。”

她没有回复，只是把手机放回口袋，走进电梯，按下法务部所在的楼层。

法务部在九楼。苏晚从电梯里出来，走过走廊，在副总监办公室门前站定。

她敲了敲门。

“进来。”

林知意坐在办公桌后面，桌上堆着一摞文件。她今年三十五岁，但看起来比实际年龄更年轻一些。苏晚上次跟她打交道是半年前，当时苏晚需要法务部确认一个数据合作协议的法律效力。

“苏晚？”林知意抬起头，眉头微微皱了一下，“有什么事？”

苏晚走进去，把门带上。

林知意的表情变了。她放下手里的笔，看着苏晚说：“坐吧。”

苏晚没有坐。她站在办公桌前面，从包里拿出一个U盘，放在桌上。

“林总监，我需要您看一些东西。”

林知意低头看着那枚U盘，没有伸手去拿。

“什么东西？”

苏晚深吸一口气。

“NightWatch。”

林知意的身体僵住了。

她没有说话，但苏晚注意到她的手指在桌面上轻轻敲了一下——这是一个无意识的动作，说明她的神经被触动了。

“你从哪里知道这个名字的？”林知意的声音很平，但苏晚能感觉到那平静下面压着的东西。

苏晚说：“姜远。了这个服务。然后失踪了。”

林知意的眼神变了。

她站起身，走到窗边，背对着苏晚站了几秒。然后她转过身，看着苏晚。

“你查到了什么？”

苏晚把过去一周查到的东西全部说了一遍。二十一个用户。RULE_032。10.0.19.42。nw-svc仓库。姜远的日志文件。恒通数据技术有限公司。省纪委。订阅客户名单。

她说得很快，像是在赶时间。

说完之后，办公室里一片沉默。

林知意站在窗边，背光的轮廓看不清表情。

过了很久，她开口了。

“你知道你在说什么吗？”

“知道。”

“你知道NightWatch的客户里有谁吗？”

苏晚说：“省纪委。”

林知意转过身，走到办公桌前，拉开抽屉，从里面拿出一个文件夹。

她把文件夹递给苏晚。

“你先看看这个。”

苏晚打开文件夹。里面是一叠打印出来的邮件截图，还有几张手写的便条。

她快速扫了一遍邮件内容，然后愣住了。

邮件的发送者是周衍，接收者是一个外部邮箱地址。邮件的内容是NightWatch的订阅客户名单——比姜远那份更详细，还多了服务期限和续费记录。

苏晚指着其中一行：“这个客户——”

林知意打断她：“对，就是你想的那个。”

苏晚看着那个名字，血液在一瞬间变凉。

那是一个她经常在新闻里看到的名字。某省属国有重要骨干企业的董事长。

这个人在商场上以手腕强硬著称，跟省里的关系盘根错节。如果他也是NightWatch的客户——

林知意说：“周衍这套系统做了三年，客户名单上有的人我不全认识，但我认识其中几个。这些人有一个共同特点。”

苏晚问：“什么特点？”

“他们都是需要监控某些'有风险'的人的企业家或官员。”

林知意走到苏晚身边，指着邮件里的一行字：“你看这个客户。他的服务内容里有一项叫'特殊区域告警'。他可以在地图上画一个圈，一旦目标进入或离开这个圈，他就会收到警报。”

苏晚明白了：“他在监控某些人。”

林知意点头：“对。而且这种监控不是通过正规渠道进行的。不需要法院批准，不需要任何手续，只要付钱给周衍，就能实现。”

苏晚沉默了几秒。

她又问：“这些邮件你从哪里拿到的？”

林知意说：“周衍的邮箱。他的工作邮箱密码很简单，我一直知道。半年前我开始怀疑他，用他的邮箱做了备份。”

苏晚说：“你为什么不报警？”

林知意苦笑了一声。

“报警？你知道周衍跟省里的关系有多深吗？他的恒通公司有省委某位领导的儿媳妇入股。NightWatch的客户里有省纪委的人。你觉得报警有用吗？”

苏晚没有说话。

林知意继续说：“我查了三年。我知道NightWatch存在，知道它的运作模式，知道它的客户是谁。但我手里的证据不够。我需要更核心的东西。”

苏晚问：“什么东西？”

林知意看着她：“NightWatch的数据库。”

苏晚愣了一下。

“数据库在nw-svc仓库里，那个仓库是私有仓库，我没有权限。”苏晚说，“而且服务器10.0.19.42不在公司资产清单里，我不知道它部署在哪里。”

林知意说：“服务器我知道在哪里。”

苏晚愣住了。

林知意走到办公桌前，打开电脑，登录了一个内网地址。

“你看。”

屏幕上是一张网络拓扑图。苏晚认出了这是公司的网络架构图，但比她平时看到的那张详细得多。

林知意指着其中一个节点：“这里。10.0.19.42。”

苏晚盯着那个IP地址，脑子飞速转动。

这个节点在公司内网的边缘地带，连接着一条专用线路，指向一个外部地址。

“这条线路通向哪里？”

林知意说：“光谷软件园的一个独立院落。没有名字，没有挂牌。物业登记显示它是某科技公司的办公地点，但这家公司只有一个人参保。”

苏晚问：“你知道这家公司的名字吗？”

林知意调出了另一份文件。

“武汉晨曦信息技术有限公司。”

苏晚想起来了。这个名字她见过。晨曦信息是周衍弟弟周明控制的公司，也是恒通数据的股东之一。

原来如此。

服务器就部署在晨曦信息的办公地点。不在公司，不在云上，在一个完全独立的环境里。

苏晚问：“你是什么时候查到这些的？”

林知意说：“三个月前。”

苏晚愣了一下：“你查到了，但你没有动手？”

林知意摇头：“我需要一个时机。晨曦信息的办公地点是私人物业，我没有合法理由进入。如果贸然行动，只会打草惊蛇。”

苏晚明白了。

林知意等了三年，就是在等一个时机。一个能把所有证据串联起来、把周衍彻底拉下水的时机。

她问林知意：“你现在有计划了吗？”

林知意说：“有。但需要你的帮助。”

苏晚看着林知意，没有说话。

林知意继续说：“姜远的日志文件里有一个细节我一直没想明白。他调用NightWatch API的时候，参数里有一个字段叫'location_history_depth=full'。这个参数意味着他不仅查了自己的实时位置，还查了自己的完整历史轨迹。”

苏晚点头：“我在姜远的日志里看到过这个。”

林知意说：“姜远能查到这个参数，说明他知道NightWatch的存在，而且知道它的查询方式。姜远不是普通人。他可能是技术出身。”

苏晚愣了一下。

她没有想过这个可能性。她一直以为姜远只是一个普通用户，被NightWatch追踪然后发现了真相。但林知意的话让她重新审视这个假设。

如果姜远懂技术，如果他知道NightWatch的API怎么调用——那他是怎么知道这些的？

林知意说：“姜远失踪前两天，nw-svc仓库有一次代码提交。提交内容是修改了NightWatch的访问控制逻辑。如果这次修改是姜远做的，那说明他当时已经获得了仓库的访问权限。”

苏晚说：“你是说姜远是内部人员？”

林知意摇头：“不。nw-svc仓库的访问权限不是员工权限能获取的。能访问那个仓库的人，要么是周衍信任的人，要么是找到了漏洞的人。”

苏晚沉默了。

她想起姜远在失踪前给她姐姐的那通电话。姜远说“我发现了一件不该发现的事”。的是NightWatch的存在。还是其他什么？

她没有答案。

就在这时，苏晚的手机震动了。

她低头一看，是一封新邮件。

发件人是一个匿名地址。正文只有一行字：

“我们知道你在查什么。停下，或者你会成为第22个。”

苏晚的血液在那一刻变凉了。

她把手机递给林知意。

林知意看了一眼，眉头皱紧了。

“邮件是从公司内网发出的。”她说，“发送者的IP是——”

她快速查了一下。

“IP是10.0.19.42。”

苏晚的后背冒了一层冷汗。

有人在监控她。而且那个人知道她在做什么。那封邮件不是警告，是宣战。

林知意沉默了几秒，然后把手机还给苏晚。

“你现在打算怎么办？”

苏晚攥着手机，盯着屏幕上的那行字。

第22个。

她想起姜远日志文件里最后一条记录：

```
[2024-09-30 14:29:47] nightwatch_svc API called
Endpoint: /v2/track
Request: {"target_id":"P_5591044728","location_history_depth":"full","scope":"realtime"}
Response: {"status":"success","location":"30.5782,114.2917","accuracy":"15m","timestamp":"2024-09-30T14:29:47Z","additional_info":{"target_name":"姜远","device_id":"xiaomi_13_8T5K92","last_seven_days_poi":["科技园C栋","光谷大道星巴克","光谷广场地铁站","星火苑小区","科技园地下停车场"]}}
```

姜远在日志里看到了自己的名字。他知道自己被追踪了。然后他就失踪了。

苏晚把手机放回口袋，看着林知意。

“我不会停。”

林知意看着她，目光复杂。

“你确定？你刚才收到的那封邮件不是威胁，是承诺。如果你继续查下去，他们会对你动手。”

苏晚点头。

“我知道。但我停不下来了。”

她顿了顿，继续说：

“我已经知道得太多了。他们不会放过我。姜远也没有停，所以姜远失踪了。我现在唯一的选择就是往前走。”

林知意沉默了很久。

然后她从桌上拿起那份文件夹，递给苏晚。

“这里面有NightWatch的完整客户名单、周衍的邮件备份、还有晨曦信息的地址。你拿走。”

苏晚接过文件夹。

林知意说：“周五晚上八点，我会去晨曦信息的办公地点。我需要你帮我做一件事。”

苏晚问：“什么事？”

林知意说：“我需要一个后备。如果我出了什么事，你要把这份名单公开出去。”

苏晚愣了一下：“你要去做什么？”

林知意没有回答。她只是看着苏晚，目光很沉。

“你愿意吗？”

苏晚攥紧手里的文件夹。

她知道林知意要去做什么。她要亲自去那个地方，去找NightWatch的服务器。

如果她成功了，她就能拿到最核心的证据。

如果她失败了——

苏晚说：“我跟你一起去。”

林知意摇头。

“不。你留在外面。如果我出事了，你需要把这个东西发出去。你是唯一的出口。”

苏晚看着林知意，嘴唇动了动，但没有发出声音。

她知道林知意是对的。

她只是一个数据分析师。她没有能力闯进一个私人场所获取证据。但林知意可以——她是法务，她有她的方式。

林知意看了看时间，已经快七点了。

“你先回去。今天晚上不要用任何电子设备，不要联网，不要登录公司的任何系统。我八点出发，十点左右会给你发消息。如果十点十五分之前你没有收到我的消息——”

她

“你就当我已经出事了。然后你按照我说的做，把名单公开。”

苏晚点头。

她转身走向门口。

走到门边的时候，她停住脚步，回头看了林知意一眼。

“林总监。”

“嗯？”

“姜远的日志文件最后一句话是什么？”

林知意愣了一下。

苏晚继续说：“日志文件的最后一行记录了什么？你看过了吗？”

林知意沉默了几秒。

然后她说：“我看过了。”

“是什么？”

林知意的声音很低：

“他们不只是监控，他们是在'抹除'——从算法里消失的人，在现实里也会消失。”

苏晚的后背在那一刻僵住了。

她想起姜远的失踪。想起那二十一个被过滤的用户。想起陈驿说的那句话：三年前，有人被追踪，然后消失了。

抹除。

这不是一个比喻。这是一个字面意义上的动作。

苏晚攥紧文件夹，转身走出办公室。

电梯下行的时候，她低头看着手里的U盘和文件夹。

姜远的日志文件她看过很多遍。日志的最后一行她已经记住了。但她刚才问林知意的问题，是她故意问的。

因为她需要确认一件事。

林知意看过日志的最后一行。她知道那句话的意思。但她今天下午还是决定去那个地方。

林知意已经做好了准备。

电梯到达负一层，门开了。

苏晚走出去，快步穿过停车场。

那辆黑色的商务车还停在那里。

她没有看它，只是快步走向出口。

她走出大楼，走进夜色里。

手机还攥在手里。十点十五分。她还有三个小时。

三个小时后，她会知道林知意是否安全。

三个小时后，她可能会变成第22个。

但她现在唯一能做的事，就是等待。

她走到地铁站，刷卡进站，坐上一班回家的列车。

车厢里人不多。她找了一个角落的位置坐下，把文件夹塞进包里，然后把手机调成静音，揣进口袋。

列车在隧道里穿行，窗外的黑暗飞速后退。

苏晚闭上眼睛，脑海里是姜远日志文件的最后一行字：

“他们不只是监控，他们是在'抹除'——从算法里消失的人，在现实里也会消失。”

她想起姜远的失踪。想起林舒华的死。想起那二十一个被过滤的用户。

抹除。

这不是一个隐喻。

这是NightWatch存在的真正意义。

它不只是一个追踪服务。它是一个抹除工具。

那些在算法里消失的人，在现实里也会消失。

姜远找到了证据，所以他消失了。

林知意今晚要去那个地方，她可能也会消失。

苏晚睁开眼睛，看着车窗玻璃上自己模糊的倒影。

她不知道自己还能撑多久。

但她知道她已经没有退路了。

列车到达下一站，苏晚站起身，走出车厢。

她要回家。等待十点十五分的到来。

等待一个答案。

或者，等待一个结局。
