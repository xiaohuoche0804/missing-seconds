# 第41章 霍明的后门

雨下了一整夜。

凌晨三点，安全屋里的电脑屏幕依然亮着。霍明坐在屏幕前，手指在键盘上飞舞，眼睛里倒映着代码的流光。他的面前摆着三块屏幕，每一块都显示着不同的数据流——周衍提供的基础设施图在某一块屏幕上浮动，像一张巨大的网络地图，而那些节点和连接线正在缓慢地发出微光。

苏晚在角落里打了个盹，方砚秋则在旁边整理报道框架的笔记。只有霍明还在工作，他的专注程度像是一个进入了深度冥想的僧侣，外界的一切都无法打扰他。

他正在做的，是将一个精巧的监控工具植入"海德拉"的数据传输管道。

这并不是普通的监控。如果只是拦截数据，那太容易触发了——"海德拉"的系统有完善的数据完整性检查，任何对数据流的干扰都会被立即标记，周衍当年就是设计这套检查机制的人之一。所以霍明换了一个思路。

"我需要的不是拦截，"他在白板上向苏晚和方砚秋解释，"而是监听。就像在电话线路上搭一个听筒，我们不挂断电话，不改变通话内容，只是在旁边听着、记录。"

但这个"听筒"的设计很复杂。霍明必须确保它不会对数据流造成任何干扰，不会留下任何痕迹，不会触发任何警报。他用了三个小时写代码，然后用三个小时测试，最后用三个小时部署——每一步都小心翼翼，如履薄冰。

现在，工具已经部署完成了。

"这就是所谓的'被动监控'。"霍明对着屏幕自言自语，声音里带着一丝满足，"不拦截数据，只记录元信息。谁在和谁通话，数据从哪里来、到哪里去，通话的时间和频率——所有的'元'数据，而不是'内容'数据。"

他轻轻地敲击键盘，一个新的窗口在屏幕上打开。，过去三个小时内，有超过2000条数据交易经过这条管道。它们的来源五花八门——社交媒体平台、电商网站、搜索引擎、数据经纪公司——但它们的流向都是同一个方向：一个被标记为"结算中心"的服务器节点。

"这就是结算日的预演吗？"霍明皱眉，"不对，结算日还有四天。为什么会有这么大的流量？"

他开始分析数据。首先是交易频率——过去72小时内，流量呈倍数级增长，从平时的每天几百笔交易，暴涨到现在的每天上万笔。其次是交易规模——单笔交易的数据量越来越大，从最初的几十KB，扩展到现在的几MB甚至几十MB。

"他们在提前囤积数据。"霍明突然明白了，"结算日之前，各平台都在把准备好的数据包提前传输到位，等待结算的那一刻统一交换。所以结算日不是一天的交易。是一个汇聚的过程。"

他开始追踪这些数据包的源头。每一条数据流都有一个起点——那是发出数据的平台标识。霍明抓取了第一批数据包的标识信息，然后与"海德拉"的交易记录进行交叉比对。

三十分钟后，了一个异常的规律。

交易记录里有一个交易对象，它使用的标识不是平台代码。是一个内部员工的工号。这个工号在系统里注册的时间很短，只在最近三个月出现过，而且出现的频率很规律——每月15号前后各三天，共六天。它只在结算周期内活跃。

霍明查了一下这个工号的注册信息。注册时间是三个月前，注册的部门是"特别项目组"，负责人的名字被加密了，但有一个字段显示了这个人的职位等级——P12。

"这不对。"霍明皱起眉头，"P12是高级架构师的级别，不可能只负责一个工号的注册。而且这个工号的使用模式太奇怪了——只在结算周期内活跃，其他时间完全沉默。这不像是一个人的工号，更像是一个'账户'。"

他开始搜索这个工号的所有交易记录。随着数据在屏幕上滚动，他的表情变得越来越凝重。

这个工号在三个月内进行了47笔交易，每一笔交易的规模都相当惊人——单笔交易的数据量从500万条到2000万条用户画像不等。这些交易的时间间隔很有意思：每两笔交易之间的间隔恰好是15天——正好是一个结算周期。

"这不是员工工号。"霍明的声音变了，"这是一个交易通道。一个被伪装成员工工号的加密交易通道。"

他继续深挖。这个通道的接收方地址更让他心惊——那不是普通的"海德拉"成员平台。是一个独立的服务器节点，位置在境外，注册的域名信息完全空白。

"有人在'海德拉'的体系之外建立了一条秘密通道。"霍明喃喃自语，"专门用于大额交易。而且这个人的权限非常高——高到可以直接绕过'海德拉'的结算系统，直接和其他平台进行对等交易。"

他开始查找这个工号的创建记录。工号的创建需要上级审批，而这条记录的审批人签名被加密了。霍明花了几分钟破解加密，然后看到了一个让他血液冰冷的名字。

审批人是陆星洲。

"陆星洲亲自批准了这条秘密通道。"霍明对着空无一人的房间说，"这不是普通的越权操作，这是他在'海德拉'的体系之外另立了一套系统。一套不受监管、不受审计、完全由他控制的系统。"

他继续追踪这条通道的交易数据。然后他看到了那笔交易。

那笔交易发生在一个月前，规模是2000万条用户画像数据，交易对象是一个匿名账户。但这笔交易最让人不安的不是规模。是它的标签。每一个数据包都有一个标签，用于标识数据的来源、类型和质量等级。而这笔交易的标签系统里，有一个特殊的字段——"高危-特殊处理"。

"高危是什么意思？"霍明开始查询这个标签的定义。在"海德拉"的内部文档里，"高危"标签的定义是："需要进行特殊处理的数据，包括但不限于：有高净值属性的用户数据、有舆论影响力的人物数据、需要进行主动干预的目标数据。"

他的手指开始发抖。

他继续查询这笔交易的具体内容。时间戳、数据量、加密序列，然后他看到了交易发起方的注册信息。

那个注册信息里有一个字段，显示的是这笔交易的原始提交人。

不是工号，不是平台代码，是一个完整的姓名。

霍明看到那个名字的瞬间，整个人僵住了。

"这不可能。"

他的声音在空旷的安全屋里回荡，带着一种难以置信的颤抖。

那个名字是苏晚。

不是同名，不是巧合，是苏晚的完整姓名、工号、注册邮箱——全部都是苏晚的真实的、完整的个人信息。

"为什么苏晚的工号会出现在这笔交易里？"霍明的声音变得尖锐，"而且是高危交易？"

他开始查这笔交易的详情。交易内容是一批用户画像数据，共计2000万条，标签是"高危-特殊处理"。交易的一个月前——正好是苏晚发现自己的账号异常、被调离原岗位、被加入监控名单的那段时间。

霍明突然想起了什么。他快速调出周衍提供的资料，翻到关于"全息画像"的那一页。那一页上写着"全息画像"的定义：

"通过整合目标的多维度数据，构建其完整的数字孪生体。包括但不限于：社交关系网络、消费行为模式、内容偏好标签、政治立场倾向、心理健康评估、关系网络强度。"

他开始对照这笔交易的标签系统。

数据字段包括：姓名、身份证号、手机号、邮箱、社交账号、地理位置历史、消费记录、浏览历史、社交关系图谱——这是完整的个人数据画像。

"这不是普通的数据交易。"霍明的声音变得冰冷，"这是'全息画像'的数据采集。而且交易的发起人是苏晚。"

他开始查苏晚的账号登录记录。然后了一个更可怕的事实。

在苏晚被调离原岗位的当天，她的工号有过一次异常登录。那次登录的时间很短，只有三分钟，但从系统日志来看，那三分钟内有一个未经授权的数据查询请求被提交了。

那个请求的内容是：查询自己的完整个人数据。

"苏晚在查询自己的数据。"霍明突然明白了，"但那个查询请求不是她自己发的。有人在用她的工号，伪造了一个查询请求。"

他快速调出那次登录的详细日志。日志显示，那个查询请求的IP地址来自"海德拉"的内部服务器，而不是苏晚的工作终端。

"有人入侵了苏晚的工号，用她的身份伪造了一个查询自己数据的请求。"霍明的声音越来越低，"然后这个请求被记录为'正常查询'，因为系统认为这是苏晚本人在查询自己的数据。但实际上，是有人在背后操控这一切。"

"目的是什么？"他继续自问自答，"为了构建苏晚的'全息画像'。因为她是内部知情者，因为她试图从内部改变规则，因为她可能是唯一一个能够深入'海德拉'内部获取证据的人。所以他们先下手为强——在她能够行动之前，先把她变成数据。"

他开始查苏晚被监控的时间线。从三个月前开始——正好是这条秘密通道建立的时间。

"这不是巧合。"霍明的声音变得很轻，但充满了愤怒，"他们在建立秘密通道的同时，就开始对苏晚进行'全息画像'。他们把她的所有数据都采集起来，构建了一个完整的数字孪生体——不是为了了解她，是为了复制她。复制她的行为模式、思维习惯、决策方式。然后用这个复制的'她'，来预测她下一步会做什么，在她行动之前先发制人。"

他开始查苏晚被调离岗位的真正原因。调离通知上写的是"组织架构调整"，但实际上那次调整的时间点，正好是在苏晚提交了针对数据滥用的内部投诉报告之后。

"他们用一个虚假的'组织架构调整'，把苏晚调离了一线岗位。"霍明的声音变得冰冷，"然后用她的工号伪造了一个'查询自己数据'的请求——这样系统就会自动认为苏晚知道了自己的数据被查询，然后触发对她的监控。实际上，苏晚根本不知道发生了什么。"

他开始查那21个被抹除者的名单。然后了一个让他血液冰冷的规律。

那21个人的共同点不只是"试图发声"，还有另一个特征——他们都曾经查询过自己的数据。

"这不是巧合。"霍明的声音开始发抖，"这是'海德拉'的标准流程。首先用虚假的请求触发目标查询自己的数据，然后以'数据安全'为由启动监控，接着逐渐升级为全面抹除。因为一个人一旦开始查询自己的数据，就意味着他开始怀疑了——而'海德拉'不能容忍任何怀疑。"

他快速关闭所有窗口，站起身，走向苏晚休息的角落。睡容疲惫，像是几天没有好好睡过。

霍明在她身边站了一会儿。她的脸在屏幕的微光中那么平静。那么普通——不像是一个即将被系统吞噬的人，不像是一个已经被复制成数据的人。

"苏晚。"他轻声叫道。

苏晚立刻睁开眼睛。那种警觉的眼神，是一个长期与数据打交道的分析师才有的直觉。

"怎么了？"

霍明沉默了一会儿。他应该告诉她吗？告诉她，她在三个月前就已经被"全息画像"了？告诉她，她的一切都已经变成了数据，变成了别人手中的工具？

"我发现了一些东西。"关于你的工号。"

苏晚的眼神立刻变得锐利。"什么东西？"

"有一笔交易，"霍明说"用你的工号发起。交易对象是2000万条用户画像数据，标签是'高危-特殊处理'。"

苏晚没有说话。她慢慢坐起身，看向霍明的眼睛。

"他们用了多长时间？"她问。

"三个月。从建立秘密通道开始。"

苏晚沉默了一会儿。然后她站起来，走到窗边，透过遮光布的缝隙看向外面。

"所以这就是为什么他们这么自信。"她"他们已经知道我的一切了。我的行为模式、思维习惯、决策方式——全部都被复制了。所以他们才敢让我留在外面，因为他们知道我会做什么——每一步都在他们的预测之中。"

"但他们没有预测到周衍会倒戈。"他们没有预测到我们会部署被动监控。他们没有预测到我们会发现结算日的时机。"

苏晚转过身，看着霍明。"你怎么知道他们没有预测到？"

霍明愣住了。

"也许这一切都在他们的计划之中。"也许他们故意让周衍'倒戈'，故意让他把那些资料交给我们。也许他们知道我们会做什么，然后在这个基础上设计新的陷阱。"

"你是说——"

"我是说，我们不知道我们是否真的在掌控局面。"苏晚的声音变得平静，"但这不能阻止我们。不管他们是否预测到了，我们唯一能做的就是做我们认为对的事。不是因为能赢。应该做。"

她走回白板前，在那张写着"倒计时：五天"的便签下面，又添了一行字：

"第四天。发现：苏晚已被全息画像。"

霍明看着那行字，然后看着苏晚。她的表情很平静，但她的眼睛里有一种他从未见过的东西——不是恐惧，不是愤怒，是一种冰冷的决心。

"还有多少时间？"她问。

霍明看了一眼屏幕上的数据。"距离结算日还有四天。但从交易记录来看，真正的数据汇聚将在结算日当天午夜前完成。所以如果我们要截获完整的证据，必须在那个时间点之前部署完毕。"

苏晚点头。"那就这样做。"她说，"我们按原计划行动——但加一个变量。"

"什么变量？"

苏晚看着那行字，然后转向霍明。"'全息画像'我的那个人是谁。"

霍明沉默了一会儿。"我查一下陆星洲的通信记录。"

"不。"我有一个更好的办法。如果那个'全息画像'是基于我的工号构建的，那么理论上，可以通过反向工程找到那个画像的核心特征——也就是我的行为模式中哪一种被标记为'危险'。"

"你是说——"

"我想知道我在他们眼里是什么样的。"苏晚"不是真实的苏晚，是被算法'理解'的苏晚。如果我能看到那个版本的我，也许就能知道他们的弱点在哪里。"

霍明看着她，眼神复杂。"这可能很危险。如果你看到的东西太真实，可能会影响你的判断。"

"我已经没有判断可以影响了。"我已经被复制成了数据。现在的关键是，让那个复制品失效。"

她走到白板前，开始在空白处画一个新的流程图。

"全息画像的关键是预测。"她说，"但预测是基于历史数据的。如果我改变我的行为模式——做一些我'正常'状态下不会做的事——那个画像就会失效。"

霍明突然明白了。"你想做那些'不可预测'的事。"

"对。"如果他们预测我会按兵不动，我就主动出击。如果他们预测我会在结算日后行动，我就提前。如果他们预测我会害怕，我就让他们看到我不害怕。"

"但这样你就会暴露在更大的危险之中——"

"我已经暴露了。"苏晚打断他，"三个月前就暴露了。现在的区别只是他们知道我在哪里。但他们不知道我会做什么。"

她放下笔，转向霍明。"所以这就是我的选择——做一个算法预测不到的人。"

霍明沉默了一会儿。然后他点头，重新坐回电脑前。

"好。"他说，"那我们来做一件算法预测不到的事——让那个秘密通道变成我们的工具。"

他开始敲击键盘，调出周衍提供的所有基础设施图。

"如果陆星洲能在'海德拉'的体系之外建立秘密通道，那说明他有足够的技术能力和权限。""但这也意味着，这条通道不受'海德拉'的监控系统的保护——因为它本身就是漏洞。"

"所以？"

"所以我们可以利用这个漏洞。"霍明的眼睛开始发光，"周衍给我们的基础设施图里，有这条通道的完整节点信息。如果我们能在结算日之前，在这条通道里植入一个反向追踪程序——"

"我们就能追踪到陆星洲的秘密交易记录。"苏晚接话，"包括那21个被抹除者的原始数据。"

"不只是追踪。"是获取。如果我们能成功植入反向追踪程序，我就能在结算日午夜之前，把所有流经这条通道的交易数据全部复制下来。"

"那些数据会包括什么？"

霍明看向屏幕。"所有的交易记录。所有的数据来源。所有的交易对象。"他顿了顿，"包括那个被标记为'苏晚'的工号交易记录。"

苏晚沉默了一会儿。然后她走到霍明身边，看着那些代码。

"多久能写出来？"

霍明估算了一下。"反向追踪程序比较复杂，需要适配陆星洲的加密协议。但我有周衍提供的加密方案文档，应该能在48小时内完成。"

"我们只有四天。"时间不够。"

"那就用另一种办法。"不用完全植入，可以做一个'镜像复制'——在结算日午夜之前，用我们的被动监控工具，拦截这条通道的数据流，然后进行实时解析。"

"能拿到多少？"

霍明看着屏幕上的数据流模拟图。"如果我们只追踪那条通道的数据流，大概能拿到60%到70%的交易记录。剩下的30%因为加密层级太深，短时间内无法解析。"

"60%到70%够吗？"

霍明想了想。"如果那些数据里包含陆星洲的秘密交易记录，就够了。"

苏晚点头。"那就这样做。"

她转向窗边，雨已经停了，天色微微发白。还有四天。四年。或者说，从她进入这个行业开始，就一直在为这一刻做准备。

"霍明。"她突然说。

"嗯？"

"谢谢你告诉我真相。"

霍明没有回答。他只是继续敲击键盘，屏幕上的代码开始滚动。苏晚看着他，突然想起了一件事。

"霍明，你有没有想过——如果你失败了，会怎么样？"

霍明的手停了一下。然后他继续敲击键盘。

"从来没想过。"他说，"我只是觉得，有些事必须有人去做。"

"小心顾维。"她说，"他不会让我们轻易成功。"

霍明点头。"我知道。"

他的手指在键盘上飞舞。霍明敲下最后一行代码。屏幕弹窗：已激活。顾维还有48小时。

与此同时，在城市另一端的一个人办公室里，陆星洲的手机屏幕亮了起来。

那是一条系统自动发送的警报——有人访问了他三个月前建立的那条秘密通道。作为审批人，他设置了最高级别的异常通知。

他盯着屏幕上的那行字看了很久。

苏晚的团队正在追踪那条通道。他们会发现那笔以苏晚自己身份发起的"高危交易"——他会成为他们眼中的"全息画像"的构建者。这不是他的设计，但他无法否认自己批准了那条规定——P12级匿名交易通道，专门用于绕过正常审计的大额数据交换。

他本可以关闭那条通道。

他本可以向顾维报告。

但他没有。

他把手机翻过来，屏幕朝下，没有回复那条警报。他看着窗外的夜色，城市的灯火在远处闪烁，像是无数条数据在流动。

十年前他创立海德拉的时候，想的是"让数据自由流动"。那时候他相信，信息不应该被困在各个平台的孤岛上，数据的融合能让人类更好地理解自己。效率不是压迫，是解放。

他依然相信。

只是他不再确定，"解放"是不是他说的那个意思。

他没有通知顾维。他也没有通知苏晚。他只是放下手机，继续坐在黑暗里，等待。

他盯着那条警报，忽然想起顾维在半年前说过的话——"在这个系统里，没有人是不可替代的。创始人也不例外。"

他鬼使神差地在终端上输入了自己的ID。

屏幕弹出一个他从未见过的界面——标签目录。标签分类："观察对象"。标签内容："创始人权限异常"、"近六个月访问日志与授权偏好偏离均值2.3个标准差"、"近期与外部调查人员关联风险上升"。最下面一行，红色字体："威胁指数——67。建议：维持监控，暂不干预。"

建立时间：六个月前。

审批人：顾维。

陆星洲盯着这行字看了很久。六个月前，正是他第一次拒绝顾维提出的"P0级全息画像"商业化方案的时候。从那一天起，他就已经在这份名单上了。

他关掉屏幕。黑暗重新吞没了办公室。

他知道了——在这个系统里，没有人是安全的。包括创建它的人。
