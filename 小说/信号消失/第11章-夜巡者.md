# 第11章 夜巡者

第二天下午，苏晚请了半天假。

她把自己关在家里，把过去一周查到的所有东西全部整理了一遍。时间线、人员名单、股权结构、数据流向，能画图的画图，能列表的列表。

晚饭后，她出发去九楼咖啡。

陈驿已经在那里了。他坐在昨天的位置，面前放着一杯没动过的咖啡。她走过去坐下的时候，发现他的脸色比昨天更差，眼睛下面有很深的青黑，像是一夜没睡。

“你看了？”

陈驿点了点头。

他没说话，只是从口袋里掏出手机，打开一个加密文件，把屏幕转向苏晚。

屏幕上是一份文档，标题是《NightWatch产品说明.pdf》。

苏晚把文档接过来，开始看。

文档的格式像是商业计划书或产品手册，但内容比她想象的详细得多。

第一页是产品概述：

```
NightWatch 个人行踪追踪服务
版本：3.2 Enterprise
运营商：武汉恒通数据技术有限公司
```

苏晚翻到第二页。

```
产品功能：
1. 实时定位：获取目标当前精确位置，误差范围15米
2. 历史轨迹：获取目标过去90天内任意时间段的出行记录
3. POI分析：自动识别目标常去地点（家、公司、常驻餐厅等）
4. 行为画像：基于出行数据生成目标的行为习惯分析报告
5. 异常警报：当目标进入或离开指定区域时触发实时通知
```

苏晚的呼吸停了一拍。

90天历史轨迹。这个数据量太大了。不是七天的POI。是九十天。

她又翻了一页。

```
订阅方案：
基础版：年费5万元，追踪目标数3个，历史轨迹保留30天
专业版：年费12万元，追踪目标数10个，历史轨迹保留90天
企业版：年费30万元起，追踪目标数不限，历史轨迹保留180天，支持API对接
```

她又翻了一页。

```
目标筛选标准：
1. 出行频次：每周使用出行平台≥3次
2. 活跃区域：常去科技园区、商务中心等区域
3. 数据完整性：平台数据覆盖度≥80%
4. 画像标签：符合"高价值商务人群"标签特征
```

苏晚盯着这四条标准看了很久。

这四条标准意味着NightWatch的订阅客户不能随便选目标。他们只能追踪那些在平台上留下足够多数据的活跃用户。

她又翻了下一页。

这一页是客户案例，但被打了码，只有一个标题：

```
某科技公司创始人夫人追踪案例
背景：客户为某上市公司高管，发现配偶有婚外情迹象
服务：定制化追踪方案，连续追踪6个月
成果：获取配偶与第三者多次幽会的证据，客户成功离婚并获得财产倾斜
```

苏晚继续翻。

下一页是另一个案例：

```
某企业竞争对手公司员工追踪案例
背景：客户怀疑竞争对手窃取商业机密
服务：定向追踪目标员工的外勤轨迹
成果：锁定内鬼身份，帮助客户在商业秘密侵权诉讼中胜诉
```

苏晚把这些案例看完，合上文档，抬头看陈驿。

“你从哪里弄到的？”

陈驿：“三年前我离开公司的时候，从周衍的办公电脑里拷出来的。当时他不在，我用他的工卡进了他的办公室。”

苏晚说：“你拿了这个东西，为什么不报警？”

陈驿冷笑了一声。

“报警？”他的语气里有一丝嘲讽，“你知道周衍跟公司的高层是什么关系吗？他是技术总监，直接向CEO汇报。这个产品是他在公司的主营业务之外另开的灶，公司高层要么不知道，要么知道但装不知道。你觉得报警有用吗？”

苏晚沉默了。

她知道陈驿说的是对的。周衍的位置太稳了，他在公司里不是一个人。

她又问：“三年前的事，你还记得多少？”

陈驿端起咖啡喝了一口，杯子已经空了。他放下杯子，靠在椅背上，开始说。

“三年前，有一个大客户找到了周衍。这个客户想追踪一个人的行踪。不是普通的婚外情或者商业竞争。是——”

他

“是什么？”

陈驿看着苏晚，眼神很沉。

“这个客户，是省里的某个领导。他的妻子在没有任何征兆的情况下失踪了。他怀疑妻子被人控制，想找到她。”

苏晚愣了一下。

“然后呢？”

“然后周衍就接了这单。他调动了NightWatch的所有资源，找到了那个女人的位置。”

“在哪儿？”

陈驿的声音压得更低了。

“在一个精神卫生中心。强制治疗。原因是她的丈夫——那个领导——向医院提供了她有精神疾病的虚假证明。”

苏晚的血液在那一刻变凉了。

她明白了。

那个领导追踪的不是别人，是他自己送进去的妻子。他给她伪造了精神疾病证明，把她关进了精神病院，然后用NightWatch追踪她的行踪，确保她不会逃跑。

他这么做是为了什么？财产？权力？还是别的什么？

她没有问出口。

但陈驿自己说了。

“那个女人最后死了。”他说，“死因是'医疗事故'。但我知道真相。她在精神病院里试图逃跑，被强制注射了过量的镇定剂，然后就没了。”

苏晚的手在桌子下面攥紧了。

陈驿继续说：“那个女人叫林舒华。她是我大学同学林知意的姐姐。”

苏晚的脑海里有什么东西在那一刻接上了。

林知意。她认识这个名字。法务部的副总监，苏晚的大学校友。但她们不在同一个学院，林知意在法学院，苏晚在计算机学院。认识是因为校友会的活动打过几次照面。

林知意的姐姐。三年前失踪，然后死在精神病院。

苏晚说：“林知意知道吗？”

陈驿摇了摇头：“不知道。或者说，她可能知道，但她没有证据。林舒华的事情被压得很死，医院那边改了病历，死亡证明也是后来补的。林知意只知道她姐姐'因病去世'，不知道背后的真相。”

苏晚沉默了很久。

她想起那天她看到的新闻，关于“林某涉嫌窃取出行平台数据”的报道。那是三年前的新闻，而林舒华死于三年前。

她有了一个猜测。

“林某是不是林舒华的妹妹？林知意的姐姐？”

陈驿点了点头。

“林舒华出事后，林知意辞掉了原来律所的工作，来了'出行的士'做法务。她来这里的唯一目的，就是找证据。”

苏晚的后背冒了一层冷汗。

林知意在找证据。她在周衍手下做事，做了三年多。她是在卧底吗？

她问陈驿：“林知意知道你在查NightWatch吗？”

陈驿摇头：“不知道。我们从来没有联系过。我离开公司之后就切断了和所有前同事的联系，包括她。”

苏晚把陈驿给她的话和之前查到的东西在脑子里过了一遍。

三年前，周衍用NightWatch帮省里某个领导追踪了他自己的妻子。林舒华。

追踪的目的是确认她被关在精神病院里。

林舒华死了。死因是医疗事故。

林知意来了“出行的士”，做公司法务。她可能是为了找证据。

NightWatch的商业模式在2023年有过一次调整，从“按次计费”变成了“年度订阅制”。

它有了稳定的客户群。

林舒华不是唯一一个受害者。

苏晚把她查到的东西告诉了陈驿：周衍的体外公司、晨曦信息和恒通数据的股权结构、NightWatch的订阅客户名单、还有“林晚”的存在。

陈驿听完，沉默了很久。

然后他说：“我当年查到的东西，没有你多。我只知道NightWatch存在，不知道它的商业模式已经规模化运营了。”

苏晚说：“周衍把这套系统做得很隐蔽。他用公司的平台数据为自己的公司服务，但公司的账上没有任何体现。RULE_032过滤掉的数据被复制到了NightWatch的数据库，这些数据不在公司的服务器上，也不在公司的任何报表里。”

陈驿点头：“这就是为什么公司高层要么不知道，要么装不知道。他们没有证据。所有的数据流向都是通过周衍的私人公司走的，跟公司主体没有任何关系。”

苏晚说：“但姜远找到了证据。”

陈驿的表情变了。

他说：“姜远不只是找到了证据。他找到了客户名单。”

苏晚愣了一下。

她想起陈驿之前说的话：姜远查到了订阅客户名单，然后他就失踪了。

客户名单是NightWatch的核心数据。有了客户名单，就能证明周衍在用平台数据为外部客户提供追踪服务。这是板上钉钉的证据。

她问陈驿：“姜远的客户名单上有多少人？”

陈驿说：“十几个。但其中有一个人的名字让姜远意识到这件事不只是商业追踪那么简单。”

“是谁？”

陈驿看着苏晚，压低了声音。

“名单上有一个人，是省纪委的。”

苏晚的脑子嗡了一下。

省纪委。

NightWatch的订阅客户里有省纪委的人。

什么？

陈驿继续说：“NightWatch不只是一个商业追踪服务。它还是一个情报收集工具。那些有钱有势的人用它来追踪他们的对手、配偶、员工。但这些人不是它唯一的客户。”

苏晚接了下去：“还有政府的人。”

陈驿点头：“对。政府的人用NightWatch来监控他们认为有问题的目标。不是通过合法程序。是通过一个商业服务私下进行。这比任何正规渠道都隐蔽，而且不留痕迹。”

苏晚终于明白了。

NightWatch的订阅客户分两类：一类是普通的有钱人，用来追踪婚外情或者商业对手；另一类是有权力的人，用来监控他们认为需要关注的目标。

后者的存在让整个事情的性质变了。

这不是一个简单的隐私侵犯问题。这是一张监控网络，渗透进了权力系统。

姜远找到了这份名单。他看到了不该看的东西。

然后他就失踪了。

苏晚把手机拿出来，打开备忘录。

她需要把今天查到的东西全部记下来。

林舒华、林知意、省纪委、订阅客户名单。

这些信息拼在一起，指向一个让她不寒而栗的事实：

NightWatch不是周衍一个人的游戏。他背后有客户，客户背后可能是更大的权力。

她问陈驿：“你有没有想过，林舒华的事情会不会跟省纪委有关？”

陈驿的表情变了。

他沉默了很久，然后说：“三年前我查到那个案例的时候，客户的身份被周衍隐藏了。但我后来通过一些渠道打听过，那个客户的身份跟省里有关系。”

省里有关系。

苏晚把这两个关键词放在一起，心里有了一个很不好的预感。

如果NightWatch的客户里有省纪委的人，那姜远找到的那份名单意味着什么？

意味着周衍手里握着一张网，网的节点连接着各种有权有势的人。这些人通过NightWatch监控他们想要关注的目标，而NightWatch的数据来源是“出行的士”的平台。

这是一个共生关系。

周衍需要平台数据来支撑他的服务，而那些有权势的客户需要他的服务来达成他们的目的。

苏晚忽然想起一件事。

她转头看陈驿：“你刚才说，林知意可能知道她在做什么。你觉得她会知道多少？”

陈驿想了想，说：“林知意在法务部做了三年多。她负责的业务里有一块是数据合规。如果她真的在找证据，她应该已经摸到了一些边。”

苏晚说：“我想见她。”

陈驿看着苏晚，没有说话。

苏晚继续说：“NightWatch的订阅客户里有省纪委的人。如果我们想把这件事公开出去，必须让更多的人知道。林知意可能是一个突破口。”

陈驿沉默了一会儿，然后说：“你知道你在做什么吗？省纪委的人不是普通人。如果NightWatch的事情被曝光，那些人会想办法压下去。你可能会——”

他没有说完，但苏晚明白他的意思。

她可能会成为第22个。

苏晚把手机放下，看着陈驿。

“你三年前发现了这件事，选择了离开。我理解你的选择。但我没有办法假装不知道。”

陈驿看着她，目光复杂。

“你确定？”

苏晚点头。

“我没有退路了。我的权限已经被收窄，他们已经注意到我了。如果我停下来，他们不会放过我。既然如此，不如往前走到底。”

陈驿沉默了很久。

最后他说：“林知意周五下午会在公司加班，她一般周四周五会在办公室待到很晚。你可以在那个时候去找她。”

苏晚把时间记下来。

周五下午。

还有两天。

她从咖啡馆出来的时候，夜风很凉。她裹紧外套，快步走向地铁站。

她不知道林知意会不会相信她。她甚至不确定林知意是不是真的在找证据。

但她需要试一试。

因为姜远已经证明了一件事：在NightWatch面前，没有人是安全的。

那些以为自己在掌控一切的人。也是被监控的对象。

这张网太大了。她站在网的中央，不知道下一步踩到的是线索还是陷阱。
