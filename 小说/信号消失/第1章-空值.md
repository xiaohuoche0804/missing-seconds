# 第1章 空值

苏晚把咖啡杯推到桌子边缘，屏幕的蓝光在镜片上折出一道细线。办公区已经没什么人了，行政部的灯最先灭掉，接着是产品那边，最后只剩下安全监控的红点和数据仓库服务器低沉的嗡鸣。

她盯着屏幕上的SQL查询结果，手指悬在键盘上方，迟迟没有落下。

二十一条。

她的月度报表脚本跑了三遍，逻辑检查了两遍，最后一次是从BI平台的审计日志里直接导出的原始数据。结论没有变：在"出行的士"平台的乘客算法模型里，有二十一个用户ID返回了null。

null不是空值。空值是字段没填，null是明确返回了"没有"。

苏晚把椅子往后推了半寸，揉了揉眉心。她在这家公司干了四年，高级数据分析师，职级P6，手下没兵但背着一个不大不小的指标。日报周报月报，ETL管道监控，异常订单检测，这些活她闭着眼都能干。但今天这个null，让她从下午三点坐到了晚上九点，咖啡凉了两杯。

她重新把光标移到查询窗口，输入第二行SQL。

```
SELECT passenger_id, 
       COUNT(*) as order_count,
       SUM(pickup_time) as last_pickup
FROM orders_all
WHERE passenger_id IN (
    -- 算法模型返回null的21个ID
)
GROUP BY passenger_id;
```

结果出来了。这二十一个人不是新用户。他们的订单表里有数据，有行程，有真实的起终点坐标，有支付记录，最近一笔订单的时间戳是去年十月十七日，凌晨两点四十三分。

算法模型返回null，但数据库有记录。

苏晚的眉头皱得更深了。她打开另一个数据库连接，进入数据清洗层。

```
SELECT *
FROM etl_filter_log
WHERE passenger_id IN (...)
AND dt BETWEEN '2024-09-01' AND '2024-12-31'
LIMIT 50;
```

结果集是空的。这二十一个人没有被清洗掉——他们根本就没进入清洗流程。清洗只对那些算法层返回null的记录生效，而这些记录是从更上游来的。

她深吸一口气，打开了数据仓库的上游日志。

上游日志显示：这二十一个ID在进入算法模型之前，字段完整，状态正常，没有任何异常标记。问题出在算法模型那一层。

苏晚切到算法模型的输入输出监控表。这张表她平时不怎么碰，是算法组的地盘，但数据分析师的读权限还是有的。

她敲下查询：

```
SELECT request_id, passenger_id, 
       input_features, 
       output_score,
       is_valid,
       created_at
FROM algo_model_score_log
WHERE passenger_id IN (...)
AND dt BETWEEN '2024-09-01' AND '2024-12-31'
LIMIT 100;
```

这一次，屏幕上跳出了数据。

二十一个人，每一个都在日志里有记录。每一条记录都是同一个字段出现了问题：is_valid = 0。

is_valid是算法模型的过滤标记。等于0的记录会被系统判定为"无效用户"，模型不会对其进行任何评分，直接返回null。

苏晚查了另外三个随机抽样的正常用户，他们在同一个时间段内的is_valid全部等于1。

二十一个人，is_valid全部等于0。不是巧合，不是数据损坏，不是系统故障。

是有人把这二十一个人打上了"无效"的标签。

她把二十一个ID导出来，存进一个本地CSV，然后在另一个窗口里打开了时间分布分析。

结果让她愣了一下。

这二十一笔订单的时间段，集中分布在去年九月中旬到十二月之间。不是每天都有，但没有任何一个月是空白的。九月中旬三笔，十月六笔，十一月六笔，十二月六笔。

呈现出一种递增的趋势。

苏晚把分析结果截图，存进自己的文档目录。她没打算汇报——至少现在没有。二十一个用户对于一个日均订单量八十万的平台来说，连零头都算不上。但如果他们是被人为过滤掉的，那问题就不只是数据问题了。

她合上笔记本电脑，收拾东西准备离开。走到电梯口的时候，她忽然停住脚步，回头看了一眼已经黑屏的工位。

二十一个人。is_valid=0。递增的时间分布。

这不像随机筛选。这像是在追查什么——或者，在抹除什么。

电梯门开了，苏晚走进去，按下负一层的按钮。

玻璃幕墙外，城市的夜景在脚下铺开，远处的科技园方向有几栋写字楼还亮着灯。她盯着那些光点，忽然想起一件事。

这二十一个人，她还没有查过他们的行程目的地。

电梯开始下降。

苏晚的脑海里，那些亮着的窗户变成了一个个问号，悬在二十一条订单记录的上方。

她知道自己明天会继续查。不是因为工作需要。了不该存在的空值。数据分析师的强迫症，这大概是她这辈子最准的自我认知。

电梯到达负一层，门开了。

苏晚走出电梯，手指无意识地敲着咖啡杯的杯壁。

那二十一个人最后一次使用平台的时间，集中在去年九月中旬到十二月之间。

她明天会去查他们的行程目的地。

明天一早，她会拿到那些行程数据。
