# 第3章 一丈青

梁山大寨，聚义厅。

“哥哥！这女人武艺高强，留着是个祸害！不如一刀杀了干净！”李逵瞪着眼珠子，嗓门震得房梁都在抖。

宋江坐在虎皮交椅上，手里端着茶盏，慢悠悠地吹了吹茶沫。

【检测到高价值目标：扈三娘（武力A+，潜力S）】
【分析中……行为模式可预测性：87%】
【发现潜在弱点：交易创伤。建议策略：证明其作为独立个体的价值。】

宋江嘴角微微上扬。

有意思。

厅堂中央，一个身形窈窕的女子被五花大绑，却依然昂着头，眼神如刀。她的武艺已被证实——连败梁山三员悍将，生擒王英，此刻虽处劣势，却毫无惧色。

一丈青扈三娘。

“好汉，还记得你擒了俺家当家的吗？”王英在旁边急得跳脚，“哥哥！这女人长得俏，不如许配给我做老婆！我不嫌她凶！”

扈三娘朝他啐了一口。

宋江放下茶盏，缓步走下堂来。

众人自动让开一条道。

他在扈三娘面前站定，上下打量了她一番。

“你不怕死？”他问。

“怕。”扈三娘冷冷道，“但死有重于泰山，有轻于鸿毛。落在你们这帮草寇手里，不过溅血五步之内，算什么大事。”

“好胆色。”宋江点头，“但你错了。”

扈三娘皱眉：“错在哪里？”

宋江没有回答，转身走回虎皮交椅，坐下。

他闭上眼睛，仿佛在思考什么。

众人面面相觑。

李逵急了：“哥哥！你倒是发句话啊！是杀是留？”

“等等。”宋江说。

他在脑中调出系统面板。

【目标：扈三娘】
【武力值：A+】
【统兵能力：B】
【心防等级：S（极高戒备）】

【行为模式分析：】
【1. 战斗风格——侵略性强，但不下死手（克制）】
【2. 被擒后——无求饶、无哭闹、无愤怒】
【3. 面对羞辱——直接反击（王英），但不主动挑事】
【4. 眼神——时刻在观察，而非单纯的愤怒】

【可预测性分析：87%】
【结论：她不是纯粹的武者。她在等待。】

宋江睁开眼，嘴角勾起一抹笑意。

他明白了。

扈三娘不是没有求生欲，而是她的骄傲不允许她表现出来。她在等一个理由——一个让她“可以”投降、而不是“被迫”投降的理由。

如果直接放她走，她会觉得自己是被施舍。

如果威逼利诱，她会觉得受到了侮辱。

这个女人的心防，不是城墙，而是——

【检测到核心创伤：被当成货物交易】
【补充信息：祝家庄覆灭后，她曾被强行许配给王英】
【分析：她的愤怒不仅来自被俘，更来自那种“身不由己”的无力感】

宋江笑了。

他站起身，走向扈三娘。

众人紧张地看着。

王英以为宋江要下令处死，急得大喊：“哥哥！别杀啊！我真想要她当老婆——”

宋江没有理他。

他在扈三娘面前停下，目光直视她的眼睛。

“你在想，”宋江轻声道，“为什么每次都是这样。”

扈三娘瞳孔微缩。

“你在想，”宋江继续说，声音平静得像在读代码，“明明是自己浴血奋战，明明是没做错任何事，结果呢？祝家庄没了，家人没了，自己成了俘虏。然后这些人——”

他指了指王英。

“就开始讨论把你许配给谁。”

扈三娘的手微微颤抖。

“你不是怕死。”宋江说，“你是怕——无论怎么挣扎，最后还是逃不掉被当成货物处置的命运。”

沉默。

死一般的沉默。

扈三娘的脸色变了。

她看着宋江的眼神，从冷漠变成震惊，从震惊变成……某种难以言喻的情绪。

“你怎么知道？”她咬牙道。

宋江笑了。

“我知道的东西多了。”

他转身，走回虎皮交椅，但没有坐下。

“但我知道的最重要的一个道理是——”他回头，看着扈三娘，“人活着，不是为了活成别人眼中的样子。”

“你不是货物。”宋江一字一顿，“你是扈三娘。扈家庄的大小姐。一丈青。梁山泊最强的女将。”

“没有人有资格把你'许配'给任何人。”

“如果有一天你愿意留在梁山，那是因为你自己选择了这里。”

“不是你欠谁的，也不是谁买你的。”

大厅里鸦雀无声。

系统面板弹出提示：

【检测到目标情绪波动：剧烈】
【心防崩溃度：47%】
【建议：给予选择权，不要施压。】

宋江点点头。

他走到扈三娘面前，亲手解开了她的绑绳。

众人惊呼。

李逵急得跳脚：“哥哥！你疯了！”

宋江抬手制止。

绳索落地。

扈三娘揉着手腕，看着宋江，眼神复杂。

“你……”她开口，声音沙哑，“你到底是什么人？”

宋江微微一笑。

“我？”他指了指自己，“我就是那个——不想让你活成别人期待样子的程序员。”

【系统提示：目标信任度+35】
【解锁隐藏属性：独立人格】
【扈三娘 状态更新：戒备心解除中……】

宋江转身，对众人说：

“从今天起，扈三娘不是谁的老婆，不是谁的俘虏。她是梁山泊的兄弟姐妹，是跟我宋江平起平坐的好汉！”

“谁能打赢她，我赏银百两！打不赢的——”

他回头看了扈三娘一眼。

“就老老实实叫声'扈姐姐好'。”

李逵不服气地嘟囔：“俺……俺才不叫……”

扈三娘却突然笑了。

是那种憋了很久、终于忍不住的笑。

“你这人真奇怪。”她说。

“你是第一个——把我当人看的。”

【系统提示：检测到好感度提升】
【目标状态：戒备→好奇】
【判定：征服完成（阶段一）】
【奖励：武力值上调 A+→S-，解锁技能"神箭"】

宋江笑眯眯地看着她。

“走吧，带你看看梁山。”

“你的房间已经备好了。被褥是新买的，热水也烧好了。”

“明天有空的话，教教那帮糙汉子怎么扎头发。”

扈三娘愣了一下，然后轻轻点头。

她跟着宋江往外走，路过王英时，连眼神都没给一个。

王英在原地石化。

李逵拍着他的肩膀，幸灾乐祸：“兄弟，你媳妇没了。”

“你闭嘴！”

---

夜深了。

宋江回到自己的屋子，系统面板自动弹出：

【章节完成奖励结算中……】
【主线任务更新：收服扈三娘 ✓】
【获得：声望+500，神秘线索×1】

宋江挑眉：“神秘线索？”

【提示：下一章揭晓】

他笑了笑，关掉面板，躺下。

窗外，梁山的灯火星星点点。

又是一个好天气。

又是一个好兆头。
