# 第22章 蔡京与金国

燕青走了三天，宋江就失眠了三天。

这倒不是思念——忠义堂里的"梁山好汉实时通讯系统"显示燕青的位置红点一直在移动，每天都有心跳包传回来，证明这位情报大师还活着。

问题是，燕青传回来的情报一条比一条离谱。

第一天："方腊势力代码架构很先进，我正在想办法潜入他们的技术团队。"

第二天："方腊本人居然是个技术天才？亲自写核心算法，比咱们梁山2.0还强。建议哥哥亲自来看看。"

第三天——也就是今天凌晨——一条加密情报直接推送到了宋江的智能手环上：

【紧急：蔡京派人秘密接触金国使者，地点在燕云古道废弃驿站。内容涉及"借兵"和"事成之后瓜分疆土"。时间：今夜子时。我在外面蹲守，需要支援请回复。】

宋江盯着这条情报，大脑宕机了整整五秒钟。

"借兵？瓜分疆土？"他自言自语，"蔡京这是要干什么？卖国吗？"

他揉了揉眼睛，确认自己没看错。元祐党争、变法革新、朝廷内斗——这些宋江都能理解，毕竟现代职场也没少见识。但堂堂北宋朝廷的一号权臣，跑去跟金国搞秘密交易，这就有点超出他的理解范围了。

"这不是八国联军侵华时期才有的剧情吗？"

宋江猛然想起自己穿越前在程序员圈子里流传的一个梗：某个外包项目的甲方拖欠款项，最后乙方直接把代码打包卖给了甲方的竞争对手。当时大家当笑话听，现在看来，这个世界比那个笑话还魔幻。

"哥哥，这么晚了还不休息？"

吴用的声音从门口传来。宋江抬头，看见军师端着一碗热腾腾的姜汤走进来，脸上带着那种"我就知道你会这样"的表情。

"军师，你看这个。"宋江把手环递过去。

吴用接过手环，看完那条情报，眉毛当场拧成了麻花——这已经成了他的标志性动作。

"蔡京……借兵金国……"吴用喃喃道，"这是要把大宋卖给外族人啊。"

宋江冷笑一声："卖不卖的不好说，但有一点可以确定——这位蔡太师比咱们梁山还着急。"

他调出系统面板，上面显示着蔡京的势力评估：

【蔡京势力评估】
【腐败度：████████░░ 85%】
【民心：███░░░░░░░ 27%】
【忠诚度：░░░░░░░░░░ 10%（只忠于利益）】
【威胁等级：S】

"85%的腐败度，比上次看又涨了5个点。"宋江摇摇头，"这老小子是真的在挖墙脚。"

吴用放下手环，在忠义堂里踱了几步，突然停下："哥哥，我有个猜测。"

"说。"

"蔡京这个人，我了解。不到万不得已，他不会走这步棋。"吴用转身看着宋江，"能让蔡京铤而走险联系金国的，只有一个原因——"

"北方战事失利？"宋江脱口而出。

"不，是咱们梁山。"吴用正色道，"哥哥，咱们北方这一仗打得辽国屁滚尿流，整个江湖都在传梁山的名号。朝廷那边，想必也坐不住了。"

宋江恍然大悟。

他一直以为自己只是在打游戏——收服山头、训练军队、南下扩张。但从朝廷的角度看，梁山从一群草寇发展成了能与辽国正面对抗的势力，这个速度已经超出了"叛乱"的范畴。

"蔡京怕了。"宋江缓缓说道，"他怕咱们梁山坐大，怕自己的权力受到威胁，所以想借金国的兵来灭咱们。"

吴用点头："但金国不是傻子。他们要的是中原的花花江山，不是跟大宋死磕之后还得瓜分战利品。所以蔡京开的价码，一定是——"

"燕云十六州。"宋江接话，"甚至更多。"

两人对视，都从对方眼中看到了同一个结论：

时间，比他们想象的更紧迫。

"给燕青回消息。"宋江果断下令，"告诉他继续盯着，必要时可以撤离。但这条情报必须拿到实锤——我要知道蔡京到底跟金国谈了什么条件。"

吴用领命而去。

宋江独自站在忠义堂里，盯着大屏幕上的战略地图。北方已经稳固，但南方的方腊还没拿下，西边又有朝廷虎视眈眈，如今再加上一个金国，这局势简直是地狱级别的并发压力。

"一个一个来。"他深吸一口气，调出系统任务面板。

【当前主线任务：席卷江南】
【阶段一：情报收集】
【进度：78%】
【负责人：燕青】

燕青还在方腊那边潜伏着，而他自己这边又发现了蔡京勾结金国的惊天大秘密。这两条线几乎是同时进行，稍有不慎就是满盘皆输。

"程序员最怕什么？"宋江自言自语，露出一个有些无奈的笑容，"最怕需求方突然改了需求，还不给你足够的开发时间。"

他打开一个新的任务窗口，开始编写代码：

```
【紧急任务：情报交叉验证】
【任务目标】分析蔡京-金国接触事件对梁山的影响
【任务类型】多线程并发分析
【输入】
- 燕青密报（蔡京-金国秘密接触）
- 时迁情报（北方天象监控数据）
- 梁山内部战力评估（当前可用兵力：65%）
【输出】
- 风险评估矩阵
- 应对策略优先级
- 时间窗口预测
【备注】系统评估：高危。建议立即处理。
```

代码运行完毕，屏幕上弹出一份详细的分析报告。

宋江扫了一眼报告内容，眉头皱得更紧了。

报告显示：按照当前局势推演，如果蔡京成功勾结金国，最快三个月内金国就会在北方边境陈兵。到那时，梁山将面临两线作战的困境——南方是方腊，北方是金国，中间还有朝廷在捅刀子。

"三个月。"宋江自言自语，"我最多只有三个月的时间。"

三个月内，必须搞定方腊，稳固南方，然后腾出手来应对金国的威胁。这时间线比他之前规划的还要紧，简直是互联网大厂"敏捷开发"的极限版本。

"哥哥，燕青那边回消息了！"吴用急匆匆跑进来，手里拿着平板，"他说有重大发现！"

宋江一把抢过平板。

屏幕上是一段视频——画质很差，明显是偷拍的，但内容足以让宋江血压飙升：

画面中，蔡京的私人代表正在跟几个穿着异族服饰的人密谈。蔡京的人从怀里掏出一张地图，上面标注着大宋的疆域，而金国使者正用手指在地图上比划着。

视频的最后，金国使者站起身，抱拳行礼，说了一句让宋江终身难忘的话：

"事成之后，燕云十六州归我大金，中原归你们蔡太师。"

然后是一阵淫笑声。

宋江把平板往桌上一放，深呼吸，再深呼吸。

"哥哥？"吴用小心翼翼地问。

"我没事。"宋江摆摆手，但语气里的冷意已经藏不住了，"我就是想给蔡京的代码加上一个死循环，让他永远在监狱里循环。"

吴用愣了愣，随即反应过来——这是宋江在用程序员的方式表达愤怒。

"哥哥，那咱们怎么办？"

宋江沉默片刻，目光落在战略地图上那片闪烁着红光的北方区域。

"三个字。"他缓缓说道，声音低沉但坚定。

"快、准、狠。"

他转身看向吴用，眼中闪着那种程序员在deadline前最后冲刺时特有的光芒：

"传令下去，南下计划加速。方腊那边，能谈就谈，不能谈就打。总之，必须在三个月内解决南方问题。"

"那金国那边呢？"

宋江冷笑一声："金国的兵还没到，我们先到。"

他打开通讯系统，给燕青发了一条加急信息：

【任务更新：新增目标——获取蔡京-金国交易详细条款。必要时可以暴露身份，但必须拿到完整情报。我会派时迁带人接应你。】

【另：注意安全。活着回来。】

发送完毕，宋江看着窗外渐亮的天色，眼神越发锐利。

E-01伏笔，这是本书里蔡京勾结金国的第一次正式登场。这个伏笔在后面的章节会不断发酵，最终成为推翻宋朝的关键导火索之一。

但现在，宋江只知道一件事：

留给他的时间，不多了。

"系统。"他低声说道。

【检测到新任务……】
【任务名称：未雨绸缪】
【任务目标：在金国介入之前解决南方问题】
【任务性质：主线】
【预计完成时间：90天】
【奖励：待定】

【系统提示：你正在改写历史。】

宋江看着这行字，忽然笑了。

"改写历史？"他在心里说道，"不好意思，我本来就是来改变这个世界的。"

窗外，梁山的晨曦照耀着忠义堂，新的一天开始了。

而在这片看似平静的水泊之下，一场席卷天下的风暴，正在悄然酝酿。
