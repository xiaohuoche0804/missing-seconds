# 第58章 金国退兵

完颜晟撤退的消息，传遍了整个北方。

宋江站在野狐岭的城楼上，看着金兵大营的灯火渐渐熄灭，心中却没有丝毫轻松。

金人退了，但他们还会回来。

而那个在暗中操控一切的敌人，还在暗处窥视着他们。

"首领。"吴用走过来，手中拿着一份刚刚收到的情报，"完颜窝幹的叛乱比我们想象的还要大。"

宋江接过情报，快速浏览。

完颜窝幹是完颜阿骨打的幼子，一直对完颜晟继承汗位心存不满。趁着完颜晟南下作战的空档，他在金国后方发动了大规模叛乱，控制的区域涵盖了金国三分之一的领土。

"完颜晟现在腹背受敌。"吴用分析道，"他要对付我们，还要对付他弟弟，兵力严重不足。"

宋江点点头："这是我们的机会。"

"首领的意思是……联合完颜窝幹？"

宋江摇头："不是联合，是利用。完颜窝幹和完颜晟的矛盾不可调和，我们不需要和他们结盟，只需要让他们互相消耗。"

"具体怎么做？"

宋江想了想："我们可以给完颜窝幹提供一些帮助——情报、武器、甚至是小股部队的配合。让他有能力继续和完颜晟对抗。"

"这样一来，金国内战爆发，完颜晟就没有精力来对付我们了。"

宋江点头："正是如此。"


消息传到金国大营，完颜晟的脸色阴沉得可怕。

他的后方正在燃烧，而梁山军又在前面虎视眈眈。

"兄长。"完颜希尹走进大帐，脸色凝重，"窝幹的叛军已经占领了上京，我们的粮道被切断了。"

完颜晟闭上眼睛。

上京是金国的政治中心，丢了上京，就等于丢了半个金国。

"还有多少时间？"他问。

"如果粮道不能恢复，我们最多撑一个月。"

一个月。

完颜晟睁开眼睛，看向地图。

野狐岭就在眼前，梁山军还在那里虎视眈眈。如果他继续进攻，可能能够拿下野狐岭，但代价是消耗大量兵力。

而他现在的兵力，已经经不起任何消耗了。

"撤兵。"完颜晟做出决定，"全军撤回金国，先平定内乱。"

完颜希尹点头："兄长英明。"

完颜晟没有说话。

他看着野狐岭的方向，看着那面在风中猎猎作响的"宋"字大旗，心中涌起一股深深的怒火。

宋江。

这个人比他想象的还要难缠。

但他没有选择。

他必须先解决完颜窝幹的问题，否则金国将从内部崩溃。


宋江站在城楼上，看着金兵缓缓撤退。

他们没有追击。

一是因为梁山军伤亡太大，没有力气追击；二是因为宋江知道，现在不是追击的时候。

金人虽然退了，但他们还有四万多人，依然是一支不可小觑的力量。

"首领。"扈三娘走过来，身上还缠着绷带，但精神已经好了很多，"金人走了。"

宋江点头："走了。但他们还会回来。"

扈三娘冷笑："来一次，我打一次。"

宋江没有说话。

他看着金兵撤退的方向，心中却在思考着另一个问题。

完颜窝幹的叛乱，是巧合吗？

他想起了因果回溯中看到的那个神秘人。

"裂缝不是自然产生的，是有人故意制造的。"

如果那个神秘人真的存在，他会不会在金国也有布局？

完颜窝幹的叛乱，会不会也是他安排的？

宋江不知道。

但他知道，他必须尽快找到答案。


战后清点伤亡。

梁山军折损一万七千人，其中战死九千余人，重伤三千余人。

扈三娘身负七处伤，其中三处是致命伤，经过军医的全力抢救，终于脱离了危险。

黎青妱的身体也恢复了一些，但她的跨次元感知能力受到了影响，短时间内无法再次使用。

金兵折损约三万人，但完颜晟的主力还在，依然是不可忽视的力量。

"这一仗，我们赢了。"吴用说，"但代价太大了。"

宋江点头。

代价太大了。

一万七千人，永远留在了野狐岭。

他们的名字，可能永远不会被后人记住。

但宋江知道，他们是这个世界的英雄。

没有他们的牺牲，就没有现在的胜利。

"传令下去。"宋江说，"厚葬所有阵亡将士，抚恤他们的家属。另外，在野狐岭立一座纪念碑，记录所有牺牲者的名字。"

吴用点头："是。"

宋江转身走回营帐。

他还有很多事情要做。

金国内战、裂缝问题、那个神秘的敌人……每一件事都需要他来处理。

但他不会退缩。

因为他知道，这是他的使命。

夜风从帐外吹入，带着一丝凉意。

宋江坐在案前，看着系统的提示，陷入了沉思。

锚点能量不够用了。

如果不尽快补充，世界之钉会越来越不稳定。

而补充的方法，一个是完成任务获得因果值，另一个是找到其他的锚点。

终南山。

他想起了那个地方。

那里有一个稳定的锚点，可以通过系统进行能量调配。

如果能把那部分能量转移过来，他的锚点能量能恢复到百分之六十以上。

"系统。"宋江问，"终南山的锚点，现在状态如何？"

【终南山锚点状态：稳定——可以通过锚点权限进行能量转移——是否执行？】

宋江沉默了一会儿。

转移能量需要他亲自前往。

但现在金人虽然退了，北方的局势依然不稳，他不能轻易离开。

"先处理完眼前的事情。"宋江说，"等局势稳定了，我再去终南山。"

【收到。】


夜深了，宋江走出营帐，仰望天空。

裂缝还在那里，但比之前暗淡了很多。

1.0%。

比之前好了一点。

但他知道，这还不够。

裂缝不是自然产生的，是有人故意制造的。

而那个"重启者"，还不知道在哪里。

他必须找到他们。

在他们彻底毁灭这个世界之前。
