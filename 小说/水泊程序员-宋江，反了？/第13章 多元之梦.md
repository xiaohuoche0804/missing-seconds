# 第13章 多元之梦

窗外是梁山深秋的夜，风刮过聚义厅的飞檐，发出低沉的呜咽。

宋江躺在床上，眼睛闭着，呼吸却越来越急促。他的眉头拧成一团，手指在被褥上无意识地抓挠，像是溺水的人在寻找什么。

他又做梦了。

这一次，他清清楚楚地知道自己在做梦——却醒不过来。


虚空中，没有天，没有地，只有无尽的黑暗。

但这黑暗里不空。

无数个光点在他周围漂浮，每一个光点都是一面镜子，映照着另一个“世界”。宋江低头看自己的手——半透明的，像是全息投影。他试着握拳，指节发出微弱的光。

【这是可能性。】

那个声音又响了。不是系统的声音，而是某种更深层的、像是从宇宙缝隙里挤出来的低语。

【你选择哪一个？】

宋江猛地转身。他看见了无数个自己——

有的穿着程序员格子衫，在某个格子间里敲代码；有的披着盔甲，站在古代战场；有的坐在龙椅上，俯视众生；有的在医院的病床前，握着某个人的手；有的站在高楼天台，俯瞰城市灯火——

每一个他，都在做不同的选择。

每一个选择，都分裂出一个新的宇宙。

“我没有选择任何一条。”宋江开口，声音在这虚空中回荡，“我只是想看清楚。”

那个声音沉默了片刻。

【你比以前更清醒了。】

“我做过这个梦。很多次。”宋江环顾四周，那些光点镜子里的景象越来越清晰，“但以前我都是被动地看着，像个观众。现在我想知道——这到底是什么？”

【可能性。】

“可能性不是这么展示的。”宋江走向最近的一面镜子，里面映出的是一个穿着西装的他，正在某个会议室里做PPT汇报，“如果只是可能性，你们不会让我'选择'。你们在让我挑一个已经发生过的现实。”

那个声音没有回答。

宋江又走向另一面镜子——里面是另一个他，正跪在某个皇帝面前，额头磕出了血。

“如果每个选择都分裂出一个宇宙，”宋江慢慢地说，声音越来越低，像是在自言自语，“那我每一个选择，都在创造一个新的我。”

他停顿了。

“而你们——系统在挑。”

【你终于开始理解了。】

“挑什么？”宋江猛地回头，“最优分支？”

虚空震颤了一下。那些光点镜子突然全部转向他，无数个他的目光汇聚在一起，像无数个摄像头同时对准了一个目标。

【你在害怕。】

“我没有——”

【你画过那张图。你记得。】

宋江的身体僵住了。

那张图。他醒来后画的那张图。分叉逻辑树。如果每一个选择都是一个if语句，那系统在做的是什么？遍历所有分支？剪枝？还是——

【你在害怕醒来。】

“我不是害怕。”宋江的声音有些发颤，“我是——不想回去。”

【回到哪里？】

“回到那个单线程的世界。”


宋江猛地睁开眼睛。

天花板。熟悉的房梁。窗外的风声。

他躺在床上，浑身是汗，像是刚从河里捞上来。枕头湿了一片，不知道是汗水还是别的什么。他伸手去摸自己的脸——滚烫的。

又是那个梦。

他坐起来，深吸一口气，又缓缓吐出。胸腔里有什么东西在狂跳，像是一台过热的CPU。

他知道自己做了什么梦。更重要的是，他知道自己在梦里说了什么。

“回到那个单线程的世界”——他不想回去。

他在怕什么？

怕回到地球？怕回到那个格子间、那个出租屋、那个只有早八晚六的生活？

还是怕——

“宋头领？”

门口传来一个声音。是花荣。

宋江揉了揉眼睛，声音尽量平稳：“怎么了？”

“没什么大事，就是——天快亮了，我还以为你已经起了。”花荣的声音从门外传来，带着一丝疑惑，“你在做噩梦？我听见你一直在说梦话。”

宋江愣了一下。“我说了什么？”

“听不太清。好像是——什么'分支'，什么'选择'。”花荣顿了顿，“要我给你倒杯水吗？”

“不用。”宋江掀开被子，脚踩在地上，冰凉的感觉让他清醒了几分，“我一会儿就出来。”

门外传来花荣离开的脚步声。

宋江坐在床边，盯着自己摊开的双手。梦里的感觉还在——那种半透明的、像是全息投影的触感。他握拳，松手，再握拳。

真实的。

他现在是真的。

但梦里的一切也他妈是真的。


半个时辰后。

聚义厅的角落里，宋江蹲在一张书案前，面前摊着好几张纸。毛笔、墨汁、还有一根炭笔——那是他让人从山下弄来的，因为他觉得毛笔画这种东西太不方便。

他画的是一棵倒置的树。

从树根开始，一条线向上分叉，分出两条；这两条各自再分出两条；如此反复，像是一棵无限生长的树。

每一根树枝的末端，他都标了注释。

根：A点（穿越前）
第一层分叉：
- 左枝（选择接受offer，留北京）：B1
- 右枝（选择拒绝，回梁山）：B2

B1继续分叉：
- 左（B1-1：5年后买房）：C1
- 右（B1-2：继续漂着）：C2

B2继续分叉：
- 左（B2-1：留在梁山，走土匪路线）：C3
- 右（B2-2：穿越成宋江，走造反路线）：C4

C3继续分叉：
- 左（C3-1：当一辈子土匪）：D1
- 右（C3-2：招安）：D2

C4继续分叉：
- 左（C4-1：招安成功，当官）：D3
- 右（C4-2：招安失败，被毒死）：D4

这是最粗略的一层。实际上，每一个分支都可以继续细分——每一个选择背后都有无数个更小的选择，像是一棵无限分叉的树。

而他画的，只是从地球到现在这段。

如果加上在梁山的这段时间，再加上——未来？

这棵树会变成什么样子？

宋江放下炭笔，盯着那棵倒置的树看了很久。

他在梦里说的那句话——"回到那个单线程的世界"——是什么意思？

那个世界，指的是地球。

单线程，指的是什么？

他盯着B2那条线——"选择拒绝，回梁山"——然后从这条线继续往下看。C4——"穿越成宋江，走造反路线"。

等等。

如果他没有穿越，他会是什么？

一个普通的程序员，在北京写代码，996，加班到死，然后——

然后什么？

然后一辈子都不会知道自己的人生还有别的可能？

还是说——

宋江猛地站起来。

不对。

他穿越了。不是"如果没穿越"，而是"已经穿越了"。这是事实，不是假设。

但那个梦里的声音说——"你在害怕醒来"。

害怕醒来——回到哪种状态？

回到穿越前？回到那个只有格子间、出租屋、996的生活？

还是回到——

宋江低头看那张图。

他突然意识到一个问题。

他画的这个分叉树，每一条分支都代表一种"可能性"。但他唯独漏掉了一条线。

他没有画"留在地球"那条线。

不是忘了画，而是——

他不想画。

因为他知道，如果画了那一条线，就意味着他在承认一个事实：还有另一个他，在那个世界里活着。没有系统，没有水浒宇宙，只是一个普通人。

但那个他——

存在吗？

宋江抓起那张纸，看了看那棵倒置的分叉树。

根节点是A点——穿越前。那一刻，他的人生是确定的。只有一条路可走：上班、加班、还房贷、慢慢老去。

然后他穿越了。

然后他的人生分裂了。

但如果他没有穿越呢？如果他就在那个世界里继续活下去呢？那条线在哪里？

他把它烧了。

那张纸。

那一整张画满了分叉逻辑树的纸。

他划了火折子，看着纸角燃起来，然后火势蔓延，把整张纸吞没。黑色的灰烬在空气中飘散，像是一群黑色的蝴蝶。

他盯着那些灰烬看了很久。

“花荣。”

“宋头领？”花荣从厅外走进来。

“今天的晨会——帮我跟晁盖哥哥说一声，我身体不舒服，不去了。”

花荣看了看宋江的脸色，又看了看桌上残留的墨迹和炭笔，点了点头：“好。我让人给你送点粥来。”

“多谢。”

花荣离开后，宋江重新坐回书案前。

他从旁边抽出一张新的纸，提笔。

这一次，他没有画树。

他写的是一行代码——不是真正的代码，而是用文字描述的伪代码：

```
function 选择(当前状态):
    if 当前状态 == "地球":
        return 选择_地球()
    else if 当前状态 == "水浒":
        return 选择_水浒()

function 选择_地球():
    // return "留在地球"
    // 但他不想写这个

function 选择_水浒():
    if 系统存在:
        return 系统.选择最优分支()
    else:
        return 随机选择()
```

他写到这里，停住了。

系统。选择最优分支。

梦里那个声音说过——"你在害怕醒来"。但它也说过另一句话："你终于开始理解了。"

理解什么？

系统不是在观察所有分支。系统是在选择。

选择最优分支。

但"最优"是谁定义的？

如果系统是"水泊梁山系统"，那最优分支是不是意味着——宋江招安成功、梁山众人都能得到好下场？

如果是这个逻辑，那他现在画的这些分支里——哪一条是系统认为的"最优"？

招安成功那条？

宋江盯着D3——"招安成功，当官"。

那是系统的目标吗？是系统在引导他走的路吗？

但梦里还有另一个他——那个跪在皇帝面前磕头的他。那是D3的另一种可能吗？还是另一条完全不同的分支？

他不知道。

他只知道一件事：他不想当那个磕头的他。

哪怕那条路是系统认为的"最优"，他也不想走。

因为他已经看到了太多分支。他知道人生不是只有一条路可走。如果他选择招安——如果他选择成为那个跪着的他——那他就再也回不来了。

回到那个单线程的世界。

回到那个没有分叉、没有选择、只有一条路走到黑的世界。

他不想。

宋江把那张写满伪代码的纸叠好，塞进怀里。

窗外的天已经大亮了。晨风吹进来，带着秋天特有的凉意。

他站起来，走到窗边。

远处的山峦层叠，雾气缭绕。梁山在晨光中显出清晰的轮廓，像是一幅水墨画。

他看着那些山，突然想起梦里看到的那些光点镜子。每一个镜子里都有一个他，在做一个不同的选择。

如果他也是一面镜子呢？

如果他此刻的选择，也在创造一个新的分支呢？

【你选择哪一个？】

那个声音又在他脑海里响起。

宋江闭上眼睛，深吸一口气。

然后他睁开眼睛，嘴角微微上扬。

“我选择继续做梦。”

他低声说，声音里带着一丝自嘲。

“反正醒着的时候也没好到哪里去。”


那天晚上，他没有再做那个梦。

但第二天醒来的时候，他发现自己枕头底下压着一张纸。

上面只写了一行字：

【你确定你的选择是你自己的吗？】

他盯着那行字看了很久。

然后，他把纸撕了。

碎片撒了一地，像是一场白色的雪。


**本章完**
