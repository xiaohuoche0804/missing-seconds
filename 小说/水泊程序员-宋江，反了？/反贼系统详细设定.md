# 《水泊程序员-宋江，反了？》反贼系统详细设定

## 系统名称
**“天工反贼系统”**

绑定条件：灵魂为反贼
终极目标：颠覆秩序，建立新朝

---

## 核心机制

### 1. 任务模块
- **日常任务**：每日刷新，小奖励
- **主线任务**：推进剧情，大奖励
- **隐藏任务**：触发式，特殊奖励
- **限时任务**：倒计时，高奖励

### 2. 结算机制
任务完成后按以下维度评级：
- **奇葩度**：操作有多出人意料
- **震撼度**：造成多大影响
- **历史颠覆度**：改变多少历史

评级：C → B → A → S → SS → SSS

### 3. 因果值
- 完成任务获得因果值
- 用于兑换物品或解锁功能
- 破坏历史进程会扣除因果值（天道惩罚）

### 4. 阵营系统
每个势力都有面板：
- 梁山好汉
- 方腊势力
- 朝廷鹰犬
- 西方诸国

### 5. 声望系统
- 民间声望
- 朝廷声望
- 绿林声望
