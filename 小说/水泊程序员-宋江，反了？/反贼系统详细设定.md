## 二、核心机制

### 1. 任务模块

| 类型 | 说明 | 频率 |
|------|------|:----:|
| 日常任务 | 每日刷新，小奖励（粮草、兵器、基础科技） | 每日 |
| 主线任务 | 推进剧情，大奖励（火炮图纸、三本神书、跨次元感知） | 剧情节点 |
| 隐藏任务 | 触发式，特殊奖励（Ω级遗迹、跨次元锚点） | 条件触发 |
| **究极隐藏任务** | **全书最高级，因果值≥100,000+声望6,480,000触发** | **一次性** |

### 2. 结算机制

任务完成后按以下维度评级：

| 维度 | 说明 |
|------|------|
| 奇葩度 | 操作有多出人意料 |
| 震撼度 | 造成多大社会/军事影响 |
| 历史颠覆度 | 改变多少历史进程 |

评级：C → B → A → S → SS → SSS
