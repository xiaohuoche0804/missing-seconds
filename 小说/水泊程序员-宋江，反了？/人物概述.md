## 一、主角

### 林墨 / 宋江

| 属性 | 内容 |
|------|------|
| **前世** | 28岁互联网大厂资深后端工程师，997猝死 |
| **性格** | 理性闷骚、数据驱动、表面仁义内心全是效益分析 |
| **核心能力** | 系统加持、程序员抽象思维、现代军事/管理知识 |
| **战力** | A级（指挥）/ S级（系统加持） |
| **成长线** | 梁山头领 → 江南霸主 → 华朝皇帝 → 全球帝王 → 枢纽守护者 |
| **标志台词** | "代码太烂，我来重构这个天下。" |

**人物弧光：**
- **前期（卷一~卷二）：** 从"我只想活下去"到"我要改变规则"。将造反当创业项目管理，逐渐被兄弟情义和扈三娘/黎青妱改变。
- **中期（卷三~卷四）：** 从"中原之主"到"位面守护者"。龙脉真相让他意识到责任远超帝国疆域。
- **后期（卷五~卷六）：** 从"征服者"到"归宿者"。遇到龙妈和旺达，完成从征服世界到守护世界的转变。

## 三、龙妈 vs 旺达 战力对比

| 对比项 | 龙妈 | 旺达 |
|--------|------|------|
| 战力类型 | 龙骑+龙焰（物理/战略级） | 混沌魔法（规则级） |
| 单兵 | S级（三龙齐出：SSS级） | SSS级（规则扭曲） |
| 群体杀伤 | 龙焰覆盖大面积 | 空间折叠+现实扭曲 |
| 战略价值 | 空中压制+闪电战 | 跨大陆投送+打破屏障 |
| 定位 | 核心战力，"矛" | 终极战力，"钥匙" |

> 没有龙妈，欧洲打不下来；没有旺达，全球征服完成不了。

## 四、核心配角

### 晁盖
- 原梁山之主 → 让位后成为帝国元老
- 第2章被宋江救活，第一个彻底信服宋江的人
- 帝国建立后主动退居二线，稳定内部的精神支柱

### 方腊
- 江南起义军领袖 → 被收服后华朝水师统帅
- 第23章孤身谈判被说服——"谈判不是零和"
- 第27章看到裂缝对面的龙——除宋江团队外第一个意识到世界不简单的人

### 林冲
- 八十万禁军教头 → 梁山核心武将
- 第15章"林冲雪恨"——全书第一个纯粹的情感高潮，一枪讨六年债

### 吴用
- 梁山军师 → 帝国谋略核心
- 唯一能在宋江用程序员术语时跟得上的人
- "KPI"这个概念他秒懂

### 公孙胜
- 入云龙 → 帝国的"超自然部门"负责人
- 第52-56章主导遗迹远征，发现五处龙脉之钉
