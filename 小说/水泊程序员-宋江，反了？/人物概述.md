# 《水泊程序员-宋江，反了？》人物概述

## 主角

### 林墨 / 宋江
- **前世**：现代程序员，996社畜，猝死
- **性格**：理性、闷骚、骨子里有野心、表面仁义内心全是效益
- **核心能力**：逻辑洞察（程序员思维）、系统外挂
- **成长线**：梁山头领 → 江南霸主 → 中原皇帝 → 全球帝王
- **经典台词**：“我写代码的时候，你还不知道在哪呢。”

- 梁山前任头领，被宋江救活，退位让贤

- 梁山军师，宋江的“诸葛亮”
- 性格：聪明、谨慎、忠诚

### 李逵
- 宋江的铁杆跟班，战力强、脑子直
- 性格：忠诚、暴躁、可爱

### 卢俊义
- 梁山战力天花板，武将之首

### 方腊
