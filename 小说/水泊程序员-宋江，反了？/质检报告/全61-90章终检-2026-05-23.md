#### BUG-1：第79章龙名冲突（CRITICAL）

**位置**：`第79章 双龙复苏.md` 第5行

**当前文本**：
```
丹妮莉丝抱着两枚龙蛋坐在龙背上，三龙在云层中穿行。她身后是两条小龙——卓耿和雷哥儿——在母亲尸体两侧伴飞，时不时发出低沉的鸣叫。
```

**问题**：在第78章（Ch78）中，已明确：
- **卓耿** = 已死的大型黑龙（母亲的坐骑），冰层碎裂后确认死亡，"灵魂消散，连龙珠都没有留下"
- **雷哥** = 绿色幼龙（从龙蛋孵出）
- **韦赛里昂** = 白色幼龙（从龙蛋孵出）

但第79章第5行将"卓耿"列为两条飞行中的**小龙之一**，这与第78章的设定直接冲突。正确的两条小龙应是"韦赛里昂和雷哥儿"。

**修复方案**：
```diff
- 她身后是两条小龙——卓耿和雷哥儿——在母亲尸体两侧伴飞
+ 她身后是两条小龙——韦赛里昂和雷哥儿——在母亲尸体两侧伴飞
```

> **附注**：同章第29行"卓耿、雷哥儿、还有另两条——都是那晚上失去的"——此处"卓耿"指代的是已死的母亲龙，作为那一晚所有丧生龙的总述，**逻辑通顺无需修改**。
