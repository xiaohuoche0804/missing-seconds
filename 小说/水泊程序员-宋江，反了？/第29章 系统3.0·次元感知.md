# 第29章 系统3.0·次元感知

那天夜里，宋江在军帐中处理完最后一批文书，照例打开系统面板做例行检查。

然后他看到了那个红色提示框。

【系统升级完毕。天工反贼系统 3.0 正在加载……】

【加载完成。新功能已解锁：次元感知（初级）。】

宋江挑了挑眉。2.0升级的时候给了他一个灰色的跨次元数据库菜单，到现在还是个摆设。3.0又会解锁什么？

他点开了新功能。

一张地图在意识中展开——不是普通的地图，是一张带着热成像效果的叠加层。地图上标注着密密麻麻的光点，每一个光点都在微微闪烁，像深夜的写字楼窗户。

"这是……"

【功能名称】次元感知（初级）
【功能描述】被动探测半径500里内的跨次元异常信号
【工作模式】相当于在WiFi列表里看到别人家的路由器——能知道它们在，但无法连接
【限制】仅能感知"信号"的存在，无法解析其内容

宋江盯着那行"WiFi列表"的描述看了三秒。

"这系统是用什么语言写的……"

他没有说完，因为他被地图上的光点数量震惊了。

从杭州往北——苏州、建康、扬州、洛阳、开封、洛阳……一个又一个光点在地图上亮起，每一个都带着微弱的信号波动。有的强，有的弱，像星星散布在夜空。

宋江下意识地往东都开封的方向看去。

那里有一个光点。

不是普通的亮——是整个地图上最亮的一个。

那个光点的信号强度是其他所有光点的总和还要多，像是在一片萤火虫中突然出现了一盏探照灯。

"这谁啊？"

【目标：黎青妱】
【位置：东京开封府】
【信号类型：跨次元感知天赋（原生）】
【信号强度：S级】
【备注：当前未被开发状态】

宋江盯着那行字，手指悬在半空中停了三秒。

黎青妱。

就是她。

那个被系统用"最高优先级保护建议"标注的女人。

宋江再次确认了那个光点的位置——开封城内，具体的坐标精确到了一条街巷。不是皇宫，不是府衙，是一个偏僻巷子里的破旧宅院。

时迁的调查报告涌上心头：黎青妱，汴京第一才女，家道中落，被朝廷冷落，住在城南的贫民区。

"信号强度S级……"宋江喃喃自语，"这女人是天生的雷达站啊。"

他用意念在地图上放大了黎青妱所在的位置。那个光点的闪烁频率和其他点都不一样——其他点是稳定的，而这个点在微微跃动，像是在接收什么。

像是有什么东西在向她发送信号。

"不对……"宋江突然意识到一个问题，"她感知到了什么？"

系统没有给他答案。

但宋江的直觉拉响了警报——如果黎青妱真的在无意识中接收跨次元信号，而她自己都不知道那些信号是什么……

这个世界像一座冰山。露出水面的只有十分之一。

而黎青妱，是水下那十分之九里最活跃的一个光点。

宋江把地图收了回去，关掉系统面板。

他需要尽快见到这个女人。

不是因为她是什么"S级信号源"——而是因为，如果她的天赋和裂缝、龙脉、五钉这些东西有关联，那她可能是整个位面最重要的本土人才。

比十个虎蹲炮图纸加起来都重要。

他拿起笔，在军用地图的开封位置上，重重画了一个圈。

旁边写下一行小字："北伐第一目标。"

吴用走进军帐的时候，正好看到那行字。

"哥哥，你这是……"

"北伐的路线调整。"宋江把地图递给他，"第一目标不是攻克开封。"

吴用看着那个圈，眉头紧锁。

"那是什么？"

"一个人。"

宋江站起身，走到军帐口，望着北方的天空。汴京在那个方向的某个地方，那里有一个女人，可能正在深夜里感知着这个世界最底层的波动，却不知道那意味着什么。

"一个比我们所有人都更了解这个世界的人。"
