# 第八十一章 西欧治理·新世界
那天晚上的宴席很特别。

宋江没有在太极殿摆宴，而是把地点选在了后宫的一处小院。这里是他日常起居的地方，没有金碧辉煌的装饰，只有一棵老槐树和几盆兰花。

扈三娘和黎青妱都已经到了。丹妮莉丝坐在宋江左手边，她怀里抱着雷哥和韦赛里昂，两条幼龙正在争抢一块肉干。

"它们还在吃奶。"丹妮莉丝说，"但它们已经开始长牙了。"

扈三娘看着那两条幼龙，眼神复杂。她想起了自己小时候在扈家庄园的日子。那时候她有一只小豹子，是父亲从西域带回来的，她养了三年，最后在祝家庄之战中被乱兵砍死了。

"你小时候养过什么？"丹妮莉丝忽然问。

扈三娘愣了一下。"一只豹子。"

"它后来怎么样了？"

"死了。"扈三娘的声音很平静，"在战争中死了。"

丹妮莉丝点了点头。"在我的世界，每个坦格利安家族的人都会有一条龙。龙是我们家族的一部分，比任何血缘关系都要紧密。"

"卓耿也死过？"扈三娘问。

"死过。"丹妮莉丝说，"它在怒火中焚烧了无数城市，最后被长枪刺穿龙颈而死。我亲眼看着它坠落。"

扈三娘没有说话。她能想象那个场景。一头巨龙从天而降，龙颈上插着长枪，火焰渐渐熄灭。那不是普通的死亡，那是某种时代的终结。

"但我没有哭。"丹妮莉丝说，"因为我知道，卓耿的火焰不会熄灭。它只是换了一种形式存在。"

她低下头，看着怀里的两条幼龙。

"雷哥和韦赛里昂就是它的火焰。"

黎青妱一直在旁边安静地听着。她的笔记本上已经写满了字，记录着丹妮莉丝说的每一句话。她对丹妮莉丝的身份很好奇——一个被冰封了一万两千年的龙族女王，她的到来意味着什么？

"丹妮莉丝。"她放下笔，"我能问你一个问题吗？"

"问。"

"你是怎么被冻住的？"

丹妮莉丝沉默了一会儿。

"是我的族人冻住我的。"她说，"当时有一个巨大的灾难即将降临到我们的世界。一个跨次元的存在想要吞噬我们整个宇宙。我们的族人联合起来，设计了一套防御系统，但需要有人来维护它。"

"所以他们选了你。"

"他们选了我的家族。"丹妮莉丝说，"一代传一代，直到灾难被彻底阻止。但那套系统失败了。防御系统没有阻止那个存在的入侵，整个宇宙都被波及了。只有我被冻在这里，保存了下来。"

"那你为什么不继续战斗？"黎青妱问。

丹妮莉丝看着她，紫色的眼眸里有什么东西在流转。

"我被冻住的时候，我的世界已经没了。"她说，"我的族人死了，我的城市毁了，我的一切都没有了。我被冻在这里，唯一能做的就是等待。等待一个程序员来终结我的冰封。"

"所以你等了一万两千年。"

"一万两千年。"丹妮莉丝点了点头，"在这段时间里，我没有任何感知。不知道外面发生了什么，不知道这个世界变成了什么样子。我就像是一段被冻结的代码，被存放在一个没有时间的地方。"

她的目光落在宋江身上。

"然后你来了。"

宋江看着她。"我说过我会来。"

"是的。"丹妮莉丝说，"你说过。"

她放下怀里的两条幼龙，端起酒杯。

"所以我来了。"

那晚的酒宴持续了很久。没有君臣之分，没有主客之别，只有四个人坐在老槐树下，喝着酒，说着话。

丹妮莉丝说起了她的世界。说起那个有龙的世界，说起她的父亲和兄长，说起她的丈夫和儿子。扈三娘说起了扈家庄园，说起了她小时候练武的日子，说起了那个被乱兵砍死的小豹子。黎青妱说起了她的父亲，说起了她在皇宫里的日子，说起了她第一次遇到宋江的情形。

宋江只是安静地听着。他想起了他穿越前的日子。在那个世界里，他只是一个普通的程序员，每天写代码，加班，吃外卖。他没有远大的理想，没有宏伟的抱负，只是想好好活着。

但现在，他坐在这里，听着三个女人说着她们的故事。

他忽然觉得，他来到了这个世界，也许真的不是偶然。

酒过三巡，菜过五味。

丹妮莉丝放下酒杯，看着宋江。

"你的帝国……"她说，"这七年都是她们在管？"

"是的。"

"你在做什么？"

宋江沉默了一会儿。"我在找裂缝的解决方案。"

"找到了吗？"

"找到了一些线索。"宋江说，"但还没有完全解决。"

丹妮莉丝点了点头。"那我帮你。"

宋江看着她。"你为什么要帮我？"

丹妮莉丝站起身，走到老槐树下，抬头看着满天的星星。

"因为我也想知道。"她说，"那个跨次元的存在到底是什么。"

她回过头，紫色的眼眸在月光下显得格外明亮。

"而且，我已经等了一万两千年了。我不想再等下去。"

宋江看着她，忽然笑了。

"好。"他说，"我们一起想办法。"

那晚的酒宴结束得很晚。当扈三娘和黎青妱离开时，已经是后半夜了。

丹妮莉丝站在院子里，看着天空中那三点微弱的光芒。雷哥和韦赛里昂正在皇宫上空盘旋，它们已经学会了飞翔，正在练习编队飞行。

"它们很喜欢这里。"她说。

宋江站在她身边。"这里能量很足，适合它们成长。"

"不只是能量。"丹妮莉丝说，"还有别的东西。"

"什么东西？"

丹妮莉丝看着他。"笑声。"

宋江愣了一下。

"在我的世界，龙是权力的象征。"丹妮莉丝说，"只有皇室的人才能骑龙，只有贵族的人才能养龙。但在这里，两条幼龙可以在皇宫上空自由飞翔，没有人觉得奇怪，没有人觉得恐惧。"

她指着天空中的那两点光芒。

"你看它们。"

宋江抬起头，看到了雷哥和韦赛里昂正在天空中追逐。它们时而俯冲，时而盘旋，发出细小的叫声，像是在玩游戏。

"它们在玩。"丹妮莉丝的声音里有一种说不出的柔软，"在我的世界，龙不会玩。龙从出生开始就被训练成武器。它们学习怎么喷火，怎么战斗，怎么毁灭。但在这里，它们在学习怎么玩。"

她转过头，看着宋江。

"你知道这意味着什么吗？"

宋江摇头。

"这意味着这个世界还有希望。"丹妮莉丝说，"一个允许龙去玩的世界，说明那里的人还有童心，还有对美好事物的向往。"

她抬起头，看着满天星星。

"我喜欢这里。"

宋江笑了。"那就留下来。"

丹妮莉丝看着他。"你不担心我吗？"

"担心什么？"

"担心我太强大了。"她说，"如果我想夺你的江山，你能拦住我吗？"

宋江沉默了一会儿。

"我拦不住。"他说，"但你不会。"

"为什么？"

"因为你不需要。"宋江说，"你有你的族人托付的使命，你有你想保护的宇宙。你不会为了一个星球的一小块土地而放弃你的使命。"

丹妮莉丝看着他，紫色的眼眸里有什么东西在流转。

"你很聪明。"她说。

"我只是程序员。"宋江说，"程序员最擅长的就是看代码逻辑。"

丹妮莉丝微微一笑。

"你是我见过的第一个程序员。"她说，"也是最让我意外的一个。"

宋江笑了。"那是因为你没遇到其他程序员。"

"也许吧。"丹妮莉丝说，"但我觉得，你是我遇到的最有意思的人。"

她转身向别院走去。

"晚安，宋江。"

"晚安，丹妮莉丝。"

她走了两步，又停下来。

"对了。"

"什么？"

"谢谢你来找我。"

宋江看着她。那个背影在月光下显得有些孤独，但也有些坚强。一万两千年的冰封没有打倒她，反而让她变得更加坚定。

"我说过我会来。"他说。

"我知道。"丹妮莉丝说，"但谢谢你真的来了。"

她走进别院，关上门。

宋江独自站在老槐树下，抬头看着天空中那两点光芒。雷哥和韦赛里昂已经停止了玩耍，正在天空中慢慢滑翔，它们的翅膀在月光下闪闪发光。

他想起了丹妮莉丝说的话。她说这个世界还有希望。一个允许龙去玩的世界，说明那里的人还有童心，还有对美好事物的向往。

他忽然觉得，他来到这个世界，也许真的不是偶然。

就像丹妮莉丝被冻在这里，也不是偶然一样。
