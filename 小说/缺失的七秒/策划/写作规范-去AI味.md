# 《缺失的七秒》写作规范 v2.0

> 2026-05-14 基于90章精炼经验总结。writer创作时严格遵守，reviewer质检时逐项检测。

---

## 一、对话标签规范（必检）

### 1.1 禁止冗余说话标签
- ❌ `"是。"宋鹤年说，"今晚。"` → ✅ `"今晚。"`
- ❌ `"知道。"方桐说，"但我不后悔。"` → ✅ `"知道。但我不后悔。"`
- ❌ 连续对话每句都加"X说" → ✅ 上下文能推断说话人的，省略标签
- **目标**：单章对话标签不超过15个（长篇对话章不超过20个）

### 1.2 禁止确认轮次
- ❌ A:"是。" B:"对。" → ✅ 直接跳到下一个信息点
- ❌ `"你确定？" "确定。"` → ✅ 删掉确认轮次

### 1.3 对话开头规范
- ❌ "你听我说，"大刘说，"不管你收到了什么……" → ✅ "不管你收到了什么，先把东西放好。"
- 删除"你听我说"等填充词

## 二、去AI味规则（创作时遵守）

### 2.1 禁止技术报告语（⚠️ 最常见问题）

**核心原则：按"对故事有无意义"判断，不按"计量类型"判断。**

| ❌ 禁止（对故事无意义） | ✅ 可保留（对故事有意义） |
|---------|---------|
| 文件大小1.2G、256G | 监控时间戳（剧情核心线索） |
| 帧率25fps、0.28秒计算 | 枪型六四式（警察标配，世界感） |
| 进针角度75-90° | 车牌号/具体地址（推动情节） |
| USB2.0接口 | 旧电脑/旧车（说"旧笔记本电脑"不用写型号） |
| 品牌型号：郎科、凯美瑞 | — |
| 哈希值/元数据/编码格式 | — |
| "时间戳显示大小" "数据显示" | — |
| 任何"数据显示/分析表明/根据XX" | — |

### 2.2 禁止"不是X而是Y"句式
- ❌ "不是恐惧，是绝望" → ✅ "不是恐惧。是绝望。"（断句）
- ❌ "不是愤怒，不是恐惧，是一种很奇怪的东西" → ✅ "不像愤怒，不像恐惧。像是在等什么。"
- ❌ "不是临时起意，是蓄谋已久" → ✅ 拆成两句或直接说"蓄谋已久"
- **规则**：每章"不是X而是Y"句式不超过1次

### 2.3 禁止微观动作描写
| ❌ 禁止 | ✅ 替代 |
|---------|--------|
| 他看见少年的手在松开 | 少年的手在松开 |
| 他注意到门缝下有一片白色 | 门缝下有一片白色 |
| 他发现刀刃离开了脖颈 | 刀刃离开了脖颈 |
| 他的目光扫过/他的眼神里 | 直接删掉 |
| 他的呼吸停了一拍 | 限每章1次 |
| 他的手指在手机背面轻轻敲了一下 | 限每章1次 |

### 2.4 禁止过度解释（⚠️ 第二大常见问题）
- ❌ 解释读者已经能推断的内容
- ❌ "这意味着/也就是说/换句话说" → 一律删除
- ❌ "刀落地的声音，镜头没拍到。但XX能想象。" → 删
- ❌ "这是XX的画面。所有人都看过的。" → 压缩成半句或删除

### 2.5 禁止人物外形堆砌
- ❌ "皮肤偏白，眼角有细纹，笑起来的时候左边嘴角会先动。这是他七年前的印象。" → 压缩到1句
- ❌ "穿着深灰色的冲锋衣和黑色工装裤，脚上是一双黑色的高帮工装靴" → "深灰冲锋衣，黑工装裤"
- **规则**：人物描写每次出场不超过1句

### 2.6 禁止文人腔/紫色散文
- ❌ "像咽下去什么" "像碎玻璃碴一样卡在脑子里"
- ❌ "车灯划破北郊的夜色"
- ❌ "光线从窗帘缝隙里挤进来，在地板上切出一条细细的光带" → 保留1句氛围描写即可
- **规则**：环境描写每次不超过3句，比喻每章不超过2个

## 三、节奏控制规范

### 3.1 章末钩子强制要求
每章最后一段必须包含以下至少一项：
- 新悬念/新信息（如"0713"）
- 倒计时压力（如"还剩XX小时"）
- 危险逼近（如"楼下站着一个男人"）
- 情感共振（如"七年了，你一个人扛了七年。够了。"）

❌ 禁止的结尾：
- "他知道自己会找到答案。但不是今晚。"（泄气）
- "XX没有回答。"（太弱）
- "他站了很久。"（模糊）

### 3.2 中段节奏
- 信息密度：每500字至少1个新信息点或情感转折
- 超过2000字的连续对话场景：必须穿插动作/环境打断
- 单个场景不要超过3000字，超过就切

### 3.3 段落长度
- 叙事段：不超过4句
- 对话段：单人不连续超过3段
- 空行分段：每200字左右需要视觉断点

## 四、质检检测清单（reviewer专用）

### A. 格式检测
- [ ] `【本章完】` 和 `章节标签：` 不得出现
- [ ] 对话标签"X说"计数 ≤15（长篇对话章≤20）
- [ ] "不是X而是Y"句式 ≤1次/章

### B. AI味检测（逐章扫描）
- [ ] `他看见/他注意到/他发现` ≤3次/章
- [ ] `他的目光/他的眼神/他的呼吸` ≤3次/章
- [ ] `声音很平/很轻/很低/很稳` = 0次
- [ ] `这意味着/也就是说/换句话说` = 0次
- [ ] 技术参数（帧率/接口型号/精确角度） = 0次
- [ ] `停顿了一下` ≤1次/章

### C. 节奏检测
- [ ] 章末钩子达标（含悬念/倒计时/危险/情感）
- [ ] 第一段能在20字内抓住注意力
- [ ] 单个场景不超过3000字
- [ ] 无连续3段以上单人对话

### D. 内容一致性（已有）
- [ ] 日期一致性（方旭案=2019.6.15）
- [ ] 人物关系一致性
- [ ] 开枪数量/方式一致性
- [ ] 跨章内容重复检测
